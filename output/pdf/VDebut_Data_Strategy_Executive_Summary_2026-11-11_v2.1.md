# VDébut 고도화 추진 요약 보고서

- 보고일: 2026-11-11
- 버전: v2.1
- 작성: VDébut 서비스 기획
- 상태: 기획·보고 문서 작성. 개발·외부 작업 미실행

## 보고 결론

신규 버튜버 발굴과 데이터 확보를 최우선으로 추진한다. 초기에는 우리가 먼저 신인을 찾아 기본 정보를 채우고, 이후 본인 등록·팬 제보를 동일한 인물·근거·갱신 구조에 연결한다.

## 현재 문제

신규 발굴 경로가 제한적이고 정보가 부족하다. 현재 치지직 조회는 인기순 최대 100개·채널 검색 첫 페이지 중심이다. 방송 목록 페이지 탐색과 키워드 검색을 별도 발굴 경로로 포함하고, 새로 발견한 인물과 최초 데뷔가 확인된 신인을 구분한다. 기존 조사·자동 채널 조회·등록·도감·상세·위키 이력은 있으나, 발굴→보강→공개→갱신의 연결이 약하다. 로컬 11월 자료는 신규 후보 32행·수정 제안 30행·조사 기록 83행이다. 각 파일의 용도가 다르므로 합계를 인원으로 계산하지 않는다. 현재 운영 DB의 누락률·실제 청구는 새로 확인하지 않았다.

## 첫 출시 핵심 3개

1. 신규 후보 발굴: 기존 조사와 허용된 치지직 방송 목록·채널 키워드 검색·다른 공개 목록을 정기 확인하고 채널 ID로 중복을 대조한다. 방송 전 홍보 검색은 접근 가능한 API가 없으면 직접 공식 링크를 조사한다.
2. 자동 보강·조건부 공개: 공식 채널 정보·소개·작품을 연결하고, 최소 조건 충족 후보는 자동 공개 대상으로 처리한다. 불명확·상충 정보는 예외 검토한다.
3. 지속 갱신·예외 관리: 변경분·근거·실패·작업 상한·삭제/철회·복구를 관리하고 기존 도감·상세에 제공한다.

직접 할 일은 출처/공개 기준 선정, 동일 인물·주요 변경·정보 충돌 판단, 표본 확인과 정정·삭제 대응이다. 모든 후보를 매번 처음부터 수작업 조사하는 구조로 고정하지 않는다.

## 개발 기본 구조와 순서

인물·채널·행사·항목별 근거·보호값·반영 이력을 분리한다. 일정 미정도 인물 후보로 보관하고, 사람이 확정한 값은 자동 수집이 덮어쓰지 않게 한다. 본인 등록·팬 제보도 같은 구조로 받는다.

현황/기준 정리 → 인물·채널·후보·근거 → 수집 연결 → 자동 보강 → 공개·복구 → 갱신·예외 → 기존 도감/상세 노출 순으로 진행하는 안이다. 기존 메인 하이라이트·실제 캘린더·Header/Footer는 유지한다. 신규 추천·게임·채팅·새 회원/소유권 관리 화면은 첫 출시 필수가 아니다.

## 추가 탐색을 반영한 예상 사용량과 비용

| 월 관리 시나리오 | 수집 호출 | DB 읽기 | DB 쓰기 | 신규 저장 예산 | 내부 순증 예산 제안 |
| --- | --- | --- | --- | --- | --- |
| 초기 100명 | 14,800회 | 112,512행 | 35,384행 | 0.05~0.15GB | 월 1만원 |
| 확장 1,000명 | 91,993회 | 849,720행 | 159,040행 | 0.25~0.75GB | 월 3만원 |

인건비는 제외한다. 사용량은 설계 가정이며, 월 1만원·3만원은 기존 검토 기준선이며 추가 탐색을 수용 가능한지 미확인이다. 공식 가격 기반 견적이 아니다. 실제 월 실비는 기존 기본료·공유 잔여량·실행 시점 단가 확인 후 산정한다. 유료 검색·SSAPI·외부 AI·전용 상시 서버는 필수 계약에 넣지 않는다.

추가 탐색은 방송 목록 3,600회+채널 검색 1,440회=월 5,040회(재시도 전) 상한 가정이다. 보강·재시도까지 포함하면 기존 9,157/85,954회에서 14,800/91,993회로 증가한다. 대량 응답은 회차 내 중복 제거·캐시 후 제한된 후보만 DB 대조한다. 외부 홍보 검색의 유료 계약·추가 본문 수집은 별도다.

## 검토 요청과 다음 숙제

- 검토 요청: 정보 공급 우선순위, 한국 치지직·SOOP 집중 범위, 자동 공개/직접 검토 경계, 초기 추가 예산의 관리 기준.
- 담당자와 Codex: 기존 후보/필드 매핑 및 첫 출처·자동 공개 규칙 정리.
- 실행 허용 이후: 접근 범위·쿼터·현재 청구/잔여량 확인, D1~D6 공동 개발.
- 운영 이후: 유효 새 인물·입문 자료 보유율·발견→공개 시간·오래된 정보·예외 시간·실제 비용으로 확대 여부 판단.

장기적으로는 자동 수집이 누락 발굴·갱신을 맡고, 본인과 팬이 소개의 깊이·대표작·정정을 보완하는 정보 플랫폼으로 발전한다. 현재 개발·외부 조회·실제 수집·DB 반영·문의·계약·결제·배포는 진행하지 않았다.
