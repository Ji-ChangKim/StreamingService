# 플랫폼 브랜드 가이드라인

> 문서명: 플랫폼 브랜드 가이드라인  
> 적용 서비스: VDEBUT (`https://vdebut.live/`)  
> 적용 대상: 웹사이트, 관리자 페이지, 홍보 이미지, SNS 게시물, 제휴·소개 자료  
> 최종 업데이트: 2026-07-31

---

## 1. 문서 목적

이 문서는 VDEBUT에서 스트리밍 플랫폼의 상표명, 로고, 아이콘 및 기타 브랜드 자산을 사용할 때 각 권리자의 브랜드 가이드라인을 침해하지 않도록 공통 기준과 플랫폼별 적용 규칙을 정의한다.

플랫폼의 공식 브랜드 가이드, 상표 정책 또는 개별 사용 허락 조건이 변경되는 경우 **해당 플랫폼의 최신 공식 기준을 이 문서보다 우선 적용한다.**

---

## 2. 기준 우선순위

브랜드 자산은 다음 우선순위에 따라 사용한다.

1. 플랫폼이 VDEBUT에 개별적으로 통지한 사용 허락 조건
2. 플랫폼의 최신 공식 브랜드 가이드
3. 플랫폼 또는 권리자의 상표·법적 고지
4. 본 문서의 VDEBUT 내부 운영 기준

기준이 서로 충돌하거나 해석이 불명확한 경우에는 로고를 임의로 사용하지 않고 해당 플랫폼에 확인한다.

---

## 3. 공통 필수 원칙

### 3.1 공식 자산만 사용

- 플랫폼이 공식 배포한 로고·아이콘 파일만 사용한다.
- 검색 결과, 캡처 이미지, 커뮤니티 게시물, 제3자 사이트에서 내려받은 파일은 사용하지 않는다.
- 공식 파일을 확보하지 못한 경우에는 로고 대신 플랫폼명을 일반 텍스트로 표시한다.
- 로고 파일을 직접 재제작하거나 유사하게 그려서 사용하지 않는다.

### 3.2 형태를 변형하지 않음

다음 가공은 금지한다.

- 가로·세로 비율 변경
- 일부 영역 자르기
- 회전, 기울기, 원근 변형
- 색상 변경 또는 단색화
- 투명도 임의 변경
- 테두리, 외곽선, 그림자, 광택, 그라데이션 추가
- 라운드 값 임의 변경
- 로고 내부 요소의 분리·재배치
- 다른 로고·아이콘·문구와 결합하여 새로운 로고처럼 제작
- 애니메이션, 깜빡임, 왜곡 효과 적용

### 3.3 공식 제휴로 오인시키지 않음

플랫폼 로고는 방송 플랫폼을 식별하고 해당 스트리머의 공식 채널로 연결하는 용도로만 사용한다.

다음 표현은 별도 계약이나 서면 허락이 없는 한 사용하지 않는다.

- 공식 파트너
- 공식 제휴
- 인증 서비스
- 공식 지원
- 공동 운영
- `VDEBUT × 플랫폼명`
- 플랫폼이 VDEBUT을 보증·승인하는 것으로 해석될 수 있는 표현

### 3.4 VDEBUT 브랜드와 분리

- 플랫폼 로고를 VDEBUT 로고의 일부로 사용하지 않는다.
- 플랫폼 로고를 VDEBUT의 파비콘, 앱 아이콘, 대표 프로필 이미지로 사용하지 않는다.
- 플랫폼 로고가 VDEBUT 로고보다 시각적으로 더 크게 보이지 않도록 한다.
- 히어로 영역이나 서비스 대표 배너에서 특정 플랫폼이 공동 운영사처럼 보이도록 배치하지 않는다.

### 3.5 로고 여백과 가독성

- 로고 주변에는 다른 아이콘, 텍스트, 카드 경계선과 구분되는 보호 여백을 확보한다.
- 플랫폼이 공식적으로 보호 공간을 규정한 경우 해당 기준을 그대로 적용한다.
- 정확한 보호 공간 수치가 공개되어 있지 않은 경우, VDEBUT 내부 기준으로 로고 높이의 최소 `25%` 이상을 사방 여백으로 확보한다.
- 로고가 배경과 충분히 구분되는 공식 버전을 선택한다.
- 임의의 배경판을 로고에 추가하지 않는다. 단, 공식 배포 자산 자체에 배경이 포함된 경우에는 그대로 사용한다.

### 3.6 링크 동작

플랫폼 로고 또는 플랫폼 배지는 원칙적으로 해당 스트리머의 공식 플랫폼 채널로 연결한다.

- 외부 링크임을 사용자가 인지할 수 있게 한다.
- 잘못된 채널, 검색 페이지 또는 비공식 미러 페이지로 연결하지 않는다.
- 링크가 없는 상태에서 로고만 클릭 가능한 것처럼 표시하지 않는다.
- 새 창 이동 시 접근성 안내를 제공한다.

### 3.7 명칭 표기

플랫폼명은 권리자가 사용하는 공식 표기를 따른다.

| 플랫폼 | 권장 표기 |
|---|---|
| 치지직 | `치지직` 또는 `CHZZK` |
| SOOP | `SOOP` |

- `Chzzk`, `CHZZK TV`, `숲TV` 등 비공식 변형 명칭은 사용하지 않는다.
- URL·DB slug 등 기술 식별자는 화면 표시명과 분리한다.

## 4. 사용 가능 위치

별도 허락 조건에 위배되지 않는 범위에서 다음 위치에만 사용한다.

- 데뷔 일정 카드의 플랫폼 식별 영역
- 스트리머 프로필의 방송 플랫폼 정보
- 플랫폼 필터
- 데뷔 상세 페이지의 공식 채널 이동 버튼
- 관리자 페이지의 플랫폼 구분 항목
- 플랫폼별 검색 결과 구분

다음 위치는 별도 검토 없이 사용하지 않는다.

- VDEBUT 메인 로고 주변
- 서비스 대표 배너
- 유료 광고 소재
- 스폰서·파트너 영역
- 굿즈 및 인쇄 판매물
- 결제 상품
- 후원·멤버십 상품
- 플랫폼 비교 우열을 강조하는 콘텐츠
- 특정 플랫폼을 비방하거나 부정적으로 평가하는 콘텐츠

## 5. 치지직(CHZZK)

### 5.1 사용 상태

**사용 허락 확인 필요**

네이버의 상표 정책에 따라 네이버의 상표와 로고는 원칙적으로 사전 사용 허락이 필요하다. 네이버 오픈API 특례가 적용되는 경우가 있으나, VDEBUT에서 치지직 로고를 플랫폼 식별 배지로 사용하는 행위가 해당 예외에 포함되는지 명확하지 않으므로 내부적으로는 **승인 필요 자산**으로 관리한다.

사용 허락이 완료되기 전에는 운영 환경에서 로고 노출을 보류하고, 필요한 경우 `치지직` 텍스트만 사용한다.

### 5.2 공식 자료

- 브랜드 가이드: `https://chzzk.gitbook.io/chzzk/resources/brand-guides`
- 네이버 상표 정책: `https://policy.naver.com/rules/disclaimer.html`

### 5.3 최소 크기

치지직 공식 브랜드 가이드의 화면용 최소 세로 크기를 준수한다.

| 자산 유형 | 디지털 최소 높이 | 인쇄 최소 높이 |
|---|---:|---:|
| 기본형 로고 | `16px` | `8mm` |
| 조합형 로고 | `22px` | `11mm` |

- 가로폭이 아니라 **세로 높이 기준**이다.
- 최소 크기는 허용 하한이며, 실제 VDEBUT 화면에서는 더 큰 크기를 사용한다.
- 로고의 `width`는 원본 비율에 맞춰 자동 계산한다.
- 모바일에서도 최소 높이 미만으로 축소하지 않는다.

### 5.4 VDEBUT 권장 크기

| 사용 위치 | 권장 규격 |
|---|---:|
| 일정 카드 아이콘 | `20 × 20px` 이상 |
| 플랫폼 필터 아이콘 | `20 × 20px` 또는 `24 × 24px` |
| 상세 페이지 플랫폼 아이콘 | `24 × 24px` |
| 기본형 워드마크 | 높이 `20px` 이상 |
| 조합형 로고 | 높이 `24px` 이상 |

치지직 아이콘의 별도 공식 최소 크기가 명시되지 않은 화면에서는 VDEBUT 내부 기준으로 `20 × 20px`을 최소값으로 사용한다.

### 5.5 사용 규칙

- 공식 배포된 치지직 로고 또는 아이콘을 그대로 사용한다.
- 공식 자산에 포함된 초록색, 검은색, 흰색 구성을 임의로 변경하지 않는다.
- 초록색 심볼만 임의로 추출하지 않는다.
- VDEBUT의 핑크색 또는 다른 테마 색상으로 변경하지 않는다.
- 어두운 배경과 밝은 배경에 맞는 공식 자산이 각각 제공되는 경우 적절한 버전을 선택한다.
- 로고를 버튼 전체 배경이나 장식 패턴으로 반복 사용하지 않는다.
- `치지직에서 보기`, `치지직 채널`처럼 이동 목적이 분명한 문구와 함께 사용할 수 있다.

### 5.6 금지 예시

- 치지직 로고를 핑크색으로 변경
- 로고에 그림자 또는 네온 효과 적용
- 로고를 원형으로 강제 마스킹
- 로고의 심볼과 문자 간격 변경
- `VDEBUT × CHZZK` 표기
- `치지직 공식 데뷔 일정` 표기
- 치지직 로고를 VDEBUT 로고 옆에 동일한 위계로 배치
- 플랫폼 필터에서 선택 상태를 표현하기 위해 로고 자체 색상을 변경

선택 상태는 로고가 아니라 버튼의 테두리, 배경 또는 체크 표시로 표현한다.

## 6. SOOP

### 6.1 사용 상태

**사전 사용 허락 신청 중 또는 승인 대기**

SOOP 브랜드를 사용하려는 경우 신청자의 연락처, 사용 목적, 노출 매체·장소, 사용 기간·지역, 구체적인 사용 방법과 계획, 브랜드 가이드 준수 확약을 포함한 서면을 제출해야 한다.

사용 허락이 완료되기 전에는 운영 환경에 SOOP 로고를 노출하지 않는다. 필요한 경우 `SOOP`을 일반 텍스트로만 표시한다.

### 6.2 신청 연락처

- 이메일: `soop@sooplive.com`
- 주소: 경기도 성남시 분당구 판교로 228번길 15 판교세븐벤처밸리 1단지 2동 9층, 주식회사 숲 브랜드 사용허락 담당자

### 6.3 VDEBUT 사용 목적

SOOP 로고는 다음 목적으로만 신청·사용한다.

- 스트리머의 활동 플랫폼 식별
- 데뷔 방송 플랫폼 안내
- 스트리머의 SOOP 공식 방송 채널 연결
- 플랫폼 검색 및 필터 구분

SOOP의 공식 서비스, 제휴 서비스 또는 공동 운영 서비스로 보이게 사용하지 않는다.

### 6.4 크기 기준

SOOP이 사용 허락 회신 또는 공식 브랜드 가이드에서 별도 최소 크기와 보호 공간을 지정하면 해당 조건을 우선 적용한다.

정확한 공식 수치가 확인되기 전까지는 다음 VDEBUT 임시 내부 기준을 적용한다.

| 사용 위치 | 임시 권장 규격 |
|---|---:|
| 일정 카드 아이콘 | `20 × 20px` 이상 |
| 플랫폼 필터 아이콘 | `20 × 20px` 또는 `24 × 24px` |
| 상세 페이지 아이콘 | `24 × 24px` |
| 워드마크 | 높이 `20px` 이상 |

이 값은 SOOP의 공식 규격이 아니라 가독성과 변형 방지를 위한 VDEBUT 내부 보수 기준이다.

### 6.5 사용 규칙

- SOOP이 제공하거나 사용을 승인한 공식 파일만 사용한다.
- 승인받은 색상, 형태, 배경 조합을 변경하지 않는다.
- `SOOP에서 보기`, `SOOP 채널`처럼 이동 목적이 명확한 문구와 함께 사용한다.
- 승인받은 매체, 위치, 기간 및 지리적 범위를 벗어나 사용하지 않는다.
- 사용 범위가 변경되면 기존 허락으로 확장 적용하지 않고 재확인한다.

## 7. UI 구현 기준

### 7.1 권장 마크업

```html
<a
  class="platform-link"
  href="{공식 채널 URL}"
  target="_blank"
  rel="noopener noreferrer"
  aria-label="{스트리머명}의 {플랫폼명} 공식 채널 열기"
>
  <img
    class="platform-logo"
    src="{공식 브랜드 자산 경로}"
    alt="{플랫폼명}"
  />
  <span>{플랫폼명}에서 보기</span>
</a>
```

장식 목적으로 중복 노출되는 로고는 `alt=""`로 처리할 수 있으나, 플랫폼 식별 기능을 담당하는 유일한 로고라면 정확한 대체 텍스트를 제공한다.

### 7.2 권장 CSS

```css
.platform-logo {
  display: block;
  width: auto;
  height: 20px;
  min-width: 0;
  object-fit: contain;
  flex: 0 0 auto;

  /* 브랜드 훼손 방지 */
  filter: none;
  transform: none;
  opacity: 1;
}

.platform-logo--detail {
  height: 24px;
}

.platform-logo--chzzk-combined {
  height: 24px;
}

.platform-link {
  display: inline-flex;
  align-items: center;
  gap: 8px;
  min-height: 36px;
}

/* 선택 상태는 로고가 아닌 컨테이너로 표현 */
.platform-filter[aria-pressed="true"] {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}
```

다음 속성은 브랜드 로고에 적용하지 않는다.

```css
filter: grayscale(...);
filter: brightness(...);
filter: drop-shadow(...);
mix-blend-mode: ...;
transform: rotate(...);
border-radius: ...; /* 공식 자산 외곽을 변경하는 경우 */
object-fit: cover;
```

### 7.3 반응형 처리

- 공간이 부족하더라도 로고를 최소 크기 아래로 줄이지 않는다.
- 좁은 화면에서는 로고를 축소하는 대신 문구를 줄이거나 레이아웃을 변경한다.
- 워드마크가 잘리는 경우 아이콘형 공식 자산으로 교체한다.
- CSS로 로고를 강제 크롭하지 않는다.
- `overflow: hidden`으로 로고 일부가 잘리지 않게 한다.

## 8. 자산 관리 기준

브랜드 파일은 다음과 같이 플랫폼별로 분리한다.

```text
/public/brands/
├─ chzzk/
│  ├─ original/
│  └─ approved/
└─ soop/
   ├─ original/
   └─ approved/
```

### 파일 관리 원칙

- `original`: 플랫폼에서 내려받은 원본 파일
- `approved`: 실제 서비스 사용이 승인된 파일
- 원본 파일을 덮어쓰지 않는다.
- 승인 여부가 불명확한 파일은 배포 빌드에서 제외한다.
- 파일명에는 임의의 `final`, `new`, `edit` 대신 플랫폼·자산 유형·버전을 기록한다.

예시:

```text
chzzk-logo-basic-ko-official.svg
chzzk-icon-square-official.svg
soop-logo-approved-2026-08.svg
```

## 9. 데이터 모델 권장안

```ts
type BrandApprovalStatus =
  | "approved"
  | "pending"
  | "text_only"
  | "prohibited";

interface PlatformBrandConfig {
  id: "chzzk" | "soop";
  displayName: string;
  approvalStatus: BrandApprovalStatus;
  logoSrc?: string;
  minDigitalHeightPx?: number;
  recommendedIconSizePx: number;
  officialGuideUrl?: string;
  channelUrlPattern?: RegExp;
}
```

운영 화면에서는 `approvalStatus`가 `approved`인 플랫폼만 이미지 로고를 노출한다.

```ts
const canRenderLogo = brand.approvalStatus === "approved";
```

승인 전에는 다음과 같이 텍스트로 대체한다.

```tsx
{canRenderLogo ? (
  <img src={brand.logoSrc} alt={brand.displayName} />
) : (
  <span>{brand.displayName}</span>
)}
```

VDEBUT의 푸터 또는 서비스 소개에 다음 문구를 표시한다.

> VDEBUT은 각 스트리밍 플랫폼의 공식 서비스가 아니며, 별도로 명시되지 않는 한 각 플랫폼과의 제휴 또는 협력을 의미하지 않습니다. 각 상표와 로고에 관한 권리는 해당 권리자에게 있습니다.

이 고지 문구는 상표 사용 허락을 대신하지 않는다.

## 11. 배포 전 체크리스트

### 권한

- [ ] 플랫폼의 사용 허락이 필요한지 확인함
- [ ] 필요한 경우 서면 승인을 받음
- [ ] 승인받은 매체·위치·기간·지역 범위 안에서 사용함
- [ ] 승인 문서 또는 이메일을 내부에 보관함

### 자산

- [ ] 공식 배포 또는 승인받은 원본 파일을 사용함
- [ ] 로고를 직접 재제작하지 않음
- [ ] 색상, 비율, 구성 요소를 변경하지 않음
- [ ] 그림자, 외곽선, 필터, 애니메이션을 적용하지 않음
- [ ] 로고 일부가 잘리지 않음

### 크기와 배치

- [ ] 공식 최소 크기 이상으로 표시함
- [ ] 충분한 보호 여백을 확보함
- [ ] 배경과 로고의 대비가 충분함
- [ ] VDEBUT 공식 로고와 혼동되지 않음
- [ ] 공식 제휴 관계로 오인될 배치가 아님

### 문구와 링크

- [ ] 플랫폼명을 공식 명칭으로 표기함
- [ ] 공식 채널 URL로 연결됨
- [ ] `공식 파트너`, `공식 제휴` 등 미승인 문구가 없음
- [ ] 외부 링크 보안 속성을 적용함
- [ ] 접근성 대체 텍스트를 제공함

## 12. 운영 및 변경 관리

다음 상황에서는 브랜드 자산을 재검토한다.

- 플랫폼이 리브랜딩한 경우
- 공식 브랜드 가이드가 변경된 경우
- VDEBUT이 광고 또는 유료 서비스를 도입한 경우
- 로고 사용 위치가 추가된 경우
- 웹사이트 외에 앱, SNS, 인쇄물 또는 영상으로 범위가 확대된 경우
- 사용 허락 기간이 만료된 경우
- 플랫폼으로부터 수정 또는 중단 요청을 받은 경우

수정 또는 중단 요청을 받으면 해당 로고를 우선 비노출하고 검토 후 재배포한다.
