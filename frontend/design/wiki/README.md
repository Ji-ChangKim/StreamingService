# VDébut 도감 개편 · 검토용 시안 01

미리보기: `http://127.0.0.1:5175/design/wiki/index.html`

기획 문서의 상세 도감·목록·정보 제보 창을 검토하기 위한 독립 화면이다. 승인된 상세·목록 본문은 운영 페이지에 반영했다. **메인 상단 하이라이트·캘린더와 Header·Footer는 기존 화면을 유지한다.** 이 시안의 제보·응원 동작은 운영 접수 기능과 구분한다.

`ExistingPortalFrame.tsx`는 현재 `PortalApp.tsx`의 Header·Footer 마크업을 그대로 사용하고 기존 `index.css`, `portal.css`, `portalRhythm.css`를 불러온다. 운영 셸 원본은 수정하지 않는다. 시안 CSS는 `.wiki-design` 본문과 `.prototype-dialog`에만 적용하여 공통 셸을 덮어쓰지 않는다. 별도 Header·Footer 디자인과 Footer 국가·언어 설정 추가안은 삭제했다.

## 검토할 화면

- **상세 도감**: 실제 공개 프로필과 진입 시 조회한 실제 영상·최신 클립, 헤더와 한 줄 채널 행, 68:32 본문·사이드바, 추천 영상·프로필·방송 활동 탭, 정보 제보 모달.
- **전체 버튜버**: 무대 배경, 헤더 배지, 아바타와 플랫폼 식별, 종족·MBTI·콘텐츠 칩, 전체 너비 도감 링크. 데스크톱 4열, 태블릿 3/2열, 모바일 2열. 원본 소개·이메일·URL을 카드에 출력하지 않는다.
- **데뷔 일정**: 운영의 기존 `CalendarPage`를 그대로 사용한다. 상단 하이라이트·플랫폼 쇼케이스·달력·검색·필터·날짜별 상세를 새 디자인으로 교체하지 않는다.
- **데뷔 전**: 상단 제어부에서 시간을 과거의 데뷔 직전으로 시뮬레이션한다. 프로필의 실제 데뷔일을 수정하지 않는다. 카운트다운·미리보기 영상·응원 방명록을 검토한다.
- **모바일**: 상단 휴대폰 버튼으로 390px 프레임을 표시한다. 실제 좁은 창과 같은 컨테이너 기반 반응형 규칙을 적용한다.

## 앞선 사용자 결정 우선 적용

- Header·Footer는 기존 화면 그대로 유지한다. 첨부 문서의 GNB 개편·Footer 설정 추가보다 사용자 범위 지시를 우선한다.
- 메인 상단 하이라이트와 캘린더도 기존 그대로 유지한다. 상세·목록 시안의 디자인을 메인에 적용하지 않는다.
- 본문 제목·탭·정보 박스·빈 상태·카드 버튼의 장식 아이콘과 반복 화살표는 제거한다. 찜하기, 닫기, 달 이동처럼 기능을 표시하는 아이콘과 공식 브랜드 원본만 남긴다.
- 문서의 '인기 클립 / 조회수 상위'는 적용하지 않고 **최신 클립 최대 4개**를 세로 카드로 표시한다.
- 문서의 탭 이름보다 앞서 확정한 **추천 영상 / 프로필**을 유지한다.
- 영상 카드는 **선명한 썸네일 + 제목**만 표시한다. 플랫폼 로고·종류·날짜·이동 안내를 반복하지 않는다.
- 채널 링크는 **한 줄, 화살표 없이, 높이 50px, 간격 8px**로 표시한다. 치지직 공식 국문 기본형 원본은 높이 24px, 사방 12px 보호 여백, 공식 `#00FFA3` 배경을 유지한다.
- 공식 그룹 식별자가 있을 때만 그룹 배지를 표시한다. 개인세·일반 소속명을 그룹으로 추측하지 않는다.
- 플랫폼 아이콘을 원형으로 강제 자르라는 문서 지시 대신, 원본 형태가 보존되는 보호 여백을 둔다.
- 검증되지 않은 수치·캐릭터 설정·일러스트레이터·리거·보이스 샘플·통계는 만들지 않는다.

## 데이터와 시연 범위

상세·목록 시안의 공개 API는 GET으로만 사용한다. 해당 시안의 관심 저장과 응원 메시지는 메모리에만 남고 새로고침하면 사라진다. 제보 모달은 필수 입력과 HTTPS 공식 출처 호스트를 검증한 다음 '시안 완료'를 표시하며 실제 POST·DB 저장·로그인·본인 인증은 수행하지 않는다. 호스트 검증은 UI 시연이며 링크 내용의 사실 검증이나 본인 인증을 대신하지 않는다. 데뷔 일정 미리보기는 기존 메인 컴포넌트를 재사용하므로 관심 저장·일정 내려받기도 기존 기능 그대로 동작한다.

방송 통계는 실제 개인 통계 데이터를 연결하기 전의 빈 그래프 레이아웃만 제공한다. 가짜 그래프, 시청자 수, 인기 점수는 사용하지 않는다. LIVE는 API가 확인한 경우에만 표시하고 데뷔 후 오프라인 배너는 생략한다.

첨부 문서가 참조하는 `image_07deb8.png`, `image_eb3b76.png` 원본은 이번 첨부에 포함되지 않아 텍스트 명세와 대화에 첨부된 화면을 기준으로 작업했다. `bg_vebut.png`도 저장소에 없으므로 보유한 `/images/spotlight_stage_bg.png`로 대체한다. 목록에는 실제 보유 `/images/bg_profile.png`를 사용한다.
