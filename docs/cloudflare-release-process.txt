VDébut Cloudflare 운영 배포 구조와 절차
기준일: 2026-10-18 KST

구성
- vdebut.live: streaming Cloudflare Worker가 Hono API와 Workers Sites KV 화면 파일을 제공한다.
  GitHub Pages와 Cloudflare Pages 프로젝트는 사용하지 않는다.
- backend/wrangler.toml: 기존 vdebut.live / dev.vdebut.live custom domain, workers.dev 및
  preview URL, D1 DB 바인딩, 운영 cron */10 * * * * 및 0 22 * * *를 명시한다.
  별도 dev.vdebut.live/* -> streaming-dev zone route도 유지한다.
- vdebut-debut-report: CRAWLER_SECRET만 가진 기존 보고 Worker다. DB·KV 바인딩은 없다.
- 새 공지 조사: GitHub Actions에서 공개 시트 본문과 선택한 읽기 API를 조사한다.
  상세 기능·승인 절차는 debut-investigation-runbook.txt를 따른다.

GitHub Pages 오류 처리 이력
- run 39019061072는 화면 빌드 후 Setup Pages에서 HTTP 404로 실패했다.
- 사용하지 않는 Pages 단계와 pages/id-token 권한을 제거하고 Cloudflare 검증으로 전환했다.

코드 검증 및 운영 코드 배포
- .github/workflows/deploy.yml: Validate and Deploy Cloudflare Worker.
- main push/PR은 의존성 설치, 화면 빌드, 서버 타입 검사, 로컬 테스트,
  Wrangler 4.151.0 운영 번들 dry-run과 검증 산출물 보관만 수행한다.
- Run workflow에서 main + deploy_production=true를 명시할 때만 운영에 배포한다.
- 검증한 동일 커밋과 화면 파일을 사용하며 D1 마이그레이션이나 SQL은 실행하지 않는다.
- 배포 후 verify_deployed_site.cjs가 운영 robots.txt를 GET으로 검증한다.
- 운영 코드 배포와 데뷔 후보 데이터 반영 승인은 서로 다른 절차다.

배포 인증 및 403
- GitHub CLOUDFLARE_API_TOKEN은 사용자 승인으로 생성한 vdebut-github-deploy 전용 토큰이다.
- 권한: 해당 계정 Workers Scripts Edit / Workers KV Storage Edit / Account Settings Read /
  D1 Read, vdebut.live Workers Routes Edit / Zone Read. D1 Edit는 없다.
- 만료: 2027-01-16 00:00 KST. 만료 전에 같은 권한으로 교체해야 한다.
- 비밀값은 GitHub 공개키로 암호화해 등록하며 평문 파일과 로그를 남기지 않는다.
- Python 기본 요청의 403은 Cloudflare 1010 클라이언트 서명 차단이었다.
  배포 점검에는 VDebut-Deployment-Check/1.0을 명시한다. 보안 설정과 인증서 검증은 유지한다.
- 실제 배포 성공 이력:
  https://github.com/Ji-ChangKim/StreamingService/actions/runs/39052163744

보고 전용 데이터 조사
- cron_crawler.yml은 매일 KST 09:00·21:00 및 수동 main 실행으로 조사한다.
- Node 조사기에는 Cloudflare 배포 토큰과 운영 DB 인증을 전달하지 않는다.
- 새 JSON/CSV/요약/승인 검토 자료와 이전 성공 보고서 비교만 생성한다.
- 메인 Worker의 기존 수동 수집과 오전 7시 데뷔 예약 수집도 보고 전용으로 전환한다.
  요청 본문 SYNC/approved/recipientEmail로 DB 반영이나 메일 발송을 켤 수 없다.
- 기타 통계 수집, 제출 신청 심사 등 기존 기능 전체를 중지한 것은 아니다.

주의할 기존 구조
- dev 설정은 기존 운영 D1을 공유한다. 로컬 테스트에는 이를 사용하지 않는다.
- 과거 마이그레이션을 일괄 실행하지 않는다. DB 반영은 별도 승인과 구현이 필요하다.
