# P0 콘텐츠 9개 페이지 검토안

2026년 10월 15일 운영 공개 API와 상세 페이지 9개를 다시 확인했습니다. 공개 소개는 378개이며, 지적한 활동명 2건·소개 재검토 1건·빈 소개 6건이 그대로 확인됐습니다. 대상 상세 URL은 모두 HTTP 200입니다. 아래는 **공식 출처를 대조한 수정 제안**이며 운영 DB 변경·콘텐츠 승인·재배포는 하지 않았습니다.

YouTube의 영상·채널 상세 설명과 SOOP 공식 방송국·본인 게시글을 브라우저에서 확인했습니다. SOOP 6개는 공식 공개 API도 HTTP 200으로 확인했습니다. 검색 결과나 팬 정리 자료만으로 활동명·소속·일정을 확정하지 않았습니다. 원자료의 공개 사실과 VDébut에서의 이미지·본문 사용 권한은 별도 확인 사항입니다.

## 1. 江口真好 — 소개 재검토

**현재 문제:** 저장 소속은 `개인세`인데 소개 원문에는 소속사가 있습니다. 성적 농담·암시를 주제로 하는 문구가 포함돼 있습니다. 저장 데뷔 일정은 2026-09-14 20:00, Asia/Seoul이며 이번 공식 채널 조회만으로 이 일정은 확정하지 못했습니다.

**공식 확인:** [본인 YouTube 채널](https://www.youtube.com/channel/UCCeSWM5OAb-ybWicrzHYJVQ)의 상세 설명에서 이름 읽기는 `えぐちまこの`, 소속은 `くえにこ!`, 현재 상태는 활동을 자제하며 조정 중이라는 안내를 확인했습니다. 공식 소개와 공개 제목에도 성적 암시가 있으므로 저장 문장에만 국한된 문제가 아닙니다.

**수정안:** 관리 자료의 활동명을 `江口真好（えぐちまこの）`, 소속을 `くえにこ!`로 정정할 근거가 있습니다. 현재 활동 안내를 기록하고 **공개는 보류**하는 안을 권합니다. 공개용 소개를 일반 잡담 버튜버로 바꿔 재승인하는 안은 제시하지 않습니다.

**운영자 확인:** 실제 대표 영상·썸네일·캐릭터 이미지·연결 자료의 성격, 현재 활동 안내의 유효성, 데뷔 공지 원본, 소속 공식 명칭, 게시 권한. 성적 암시와 명백한 음란 콘텐츠는 정책상 판단이 다르므로 이번 텍스트 확인만으로 Google 위반 확정이나 승인 가능 판정을 내리지 않습니다. [Google 성적인 콘텐츠 제한사항](https://support.google.com/publisherpolicies/answer/10400657?hl=ko), [게시자 정책](https://support.google.com/publisherpolicies/answer/10502938?hl=ko)

- 채널: `https://www.youtube.com/@seizon_nanoka`
- X: `https://x.com/seizon_nanoka`
