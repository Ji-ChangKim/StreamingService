[최신 콘텐츠 패치 보고서](adsense-p0-content-patch-report.md)

2026년 10월 15일 기준 운영 패치와 대상 공식 정정은 완료했지만, **실제 권리·운영 고지·문의 수신·계정 설정 확인을 마치기 전에는 AdSense 신청을 보류하는 것이 적절합니다.** Google의 심사 결과를 예측한 판단이 아니라 남은 확인 항목을 기준으로 한 내부 신청 기준입니다.

개발에서 검증한 P0~P2 코드와 공식 정정을 [운영 사이트](https://vdebut.live/guide)에 반영하고 실제 주소를 검수했습니다. 개발 사이트는 검색·크롤러 차단을 유지합니다. 콘텐츠·권리 일괄 승인은 생성하지 않았습니다. 아래 16:10 수치는 반영 전 기록입니다. [앞선 개발 패치 빌드 보고서](adsense-dev-build-report.md)

사이트 연결에는 계정이 안내하는 코드·ads.txt·메타 태그 중 실제 선택한 방법을 적용해야 합니다. 사이트 확인에 문제가 있으면 Mediapartners-Google과 Google-Display-Ads-Bot의 접근도 확인해야 합니다. [Google 사이트 연결 안내](https://support.google.com/adsense/answer/12169212?hl=ko)

개인 맞춤 광고를 EEA·영국·스위스 이용자에게 제공할 경우 Google의 인증 CMP 요건을 확인해야 합니다. 현재 방문 지역·계정 설정은 확정하지 않았습니다. [Google 동의 관리 요건](https://support.google.com/adsense/answer/13554116?hl=ko)
