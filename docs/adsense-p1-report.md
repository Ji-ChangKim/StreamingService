# AdSense P1 반영 보고서

메인 페이지, 버튜버 상세 소개, 이용 가이드와 통계 해설을 실제 서비스 동작과 저장 자료에 맞춰 보강했습니다. 2026년 10월 15일 로컬 코드 기준이며, 운영 배포와 원격 DB 변경은 수행하지 않았습니다. 개별 버튜버의 특징·방송 계획·언어·소속을 새로 만들거나 기존 소개를 일괄 승인하지 않았습니다.

## 페이지별 변경

| 페이지 | 반영 내용 | 실제 문구 예시 |
| --- | --- | --- |
| 메인 `/` | 탐색·관심 저장·캘린더 저장 설명, 일정 보기·등록 동작, 등록 자료임을 밝힌 집계, 이번 주 일정의 플랫폼 분포와 날짜순 소개 최대 6건, 가이드 3편 연결 | “치지직·SOOP·YouTube·Twitch의 데뷔 일정과 소개를 살펴보세요. 관심 있는 버튜버를 저장하고, 첫 방송 일정을 내 캘린더에 담을 수 있어요.” |
| 상세 `/creator/:slug` | 전체 소개 원문과 주요 콘텐츠·방송 언어를 구분, 실제 승인 검토일과 등록 공지 링크, 저장 안내 연결 | “어떤 방송을 하나요?”, “소개 검토일”, “공지가 바뀌면 저장한 캘린더 일정도 직접 수정해 주세요.” |
| 가이드 `/guide` | 서비스 소개와 주소·본문 분리, 목차와 항목별 바로가기, 저장·시간대·소개 작성·공지 변경·통계 활용 5편, 각 글의 다음 행동 연결 | “저장한 일정은 자동 구독이 아닙니다. 데뷔 공지가 바뀌면 개인 캘린더의 날짜와 시간도 직접 수정해 주세요.” |
| 서비스 `/about` | 기능 중심 소개를 유지하고 상세 절차는 가이드에 연결 | “데뷔 일정과 방송 소개로 버튜버와 팬의 첫 만남을 연결합니다.” |
| 통계 `/analytics` 및 개인 통계 | 기간·플랫폼·활동과 시작 지표·연속 기록 시간·카테고리 중복·0과 기록 없음의 차이를 펼침 안내로 제공 | “전체 통계의 방송 활동은 시간대별 평균 방송 채널 수, 개인 통계는 기록된 시점의 방송 활동 비율입니다.” |
| 빈 통계 | 신규 채널·수집 시작·10분 모니터링 등의 추측 문구 제거, 조회 조건 변경 안내 | “선택한 기간과 조건에 맞는 방송 기록이 없어요.” |

메인 카드와 달력 상세 목록은 입력된 한 줄 소개를 우선하고, 없으면 소개 원문의 앞부분을 표시합니다. 상세 페이지는 전체 원문을 유지합니다. 주간 일정은 선택한 시간대 기준 일요일부터 토요일까지이며, 시간 미정은 공지된 날짜를 유지하고 날짜 미정·일정 없는 소개는 주간 집계에서 제외합니다. 메인 주간 안내는 공개 목록 전체를 사용하고 달력의 국가·플랫폼·검색 필터와 독립적으로 표시합니다.

새 안내 글은 한국어·일본어·영어 번역을 제공합니다. 활동명·소개 원문·태그 등 등록 정보는 번역하거나 재작성하지 않습니다. 최초 HTML에도 가이드 전문, 승인된 상세 소개와 통계 해설을 넣고, 언어별 메타 설명과 가이드 링크를 반영했습니다.

## PAS 흐름

- Problem: 첫 방송의 날짜·채널과 어떤 콘텐츠인지 찾기 어렵다는 문제를 메인에서 다룹니다.
- Agitation: 시차로 날짜가 달라지거나 저장한 일정이 자동 갱신되지 않는 실제 이용상의 혼동을 가이드에서 설명합니다.
- Solution: 등록 자료 탐색 → 상세 소개와 공지 확인 → 관심·일정 저장으로 이어집니다. 데뷔 준비자는 소개 작성 → 공지 준비 → 등록 → 변경 요청으로 이동할 수 있습니다.

- `frontend/src/portal/PortalStage.tsx`, `CalendarPage.tsx`, `PortalUi.tsx`: 메인 동작·주간 안내 연결·소개 발췌.

- `frontend/src/portal/CreatorProfile.tsx`: 실제 소개 항목·검토 기록·공지와 저장 안내.
- `frontend/src/portal/PortalApp.tsx`, `InfoPages.tsx`: 가이드 경로 분리와 푸터 연결, 서비스 소개 정리.
- `frontend/src/portal/PortalStatistics.tsx`: 기록된 콘텐츠 중심의 통계 도입문.
- `frontend/src/components/analytics/ActivityDashboard.tsx`, `ActivityReadingGuide.tsx`, `activityDashboard.css`: 기록 기반 요약, 빈 상태, 통계 읽기 안내.
- `backend/src/services/portalEditorialBody.ts`, `portalPageService.ts`, `activityPageService.ts`: 서버 초기 HTML의 안내·소개·해설.
- `frontend/tests/portalEditorial.test.cjs`: 시간대·번역·공개 기준·HTML 안전성·통계 요약 회귀 검증.
- `docs/adsense-operational-confirmations.md`: 확인되지 않은 운영·콘텐츠 정보와 후속 작업.

빌드의 첫 시도는 샌드박스의 `index.html` realpath 접근 제한으로 중단됐으며, 같은 작업의 실행 권한을 확보해 최종 빌드를 통과했습니다. 기존 테스트용 축약 DB의 컬럼 누락 경고와 Node SQLite 실험 기능 경고가 출력되지만 관련 테스트는 통과했습니다.

브라우저 검증은 실제 Worker를 로컬 메모리 DB에 연결해 수행했습니다. 화면의 “P1 검증용 버튜버”는 로컬에서만 생성한 테스트 자료이며 제품 데이터에 포함하지 않습니다. 이 로컬 브리지에는 Cloudflare Cache API가 없으므로 실시간 순위 영역은 조회 실패로 표시됐습니다. 이번 통계 검증 범위는 빈 기록 안내와 해설의 표시·상호작용이며, 운영 실시간 수집 상태는 검증하지 않았습니다.

## 신청 전 남은 확인

실제 주력 콘텐츠와 첫 방송 계획이 빈 소개는 공식 채널 또는 당사자에게 확인한 뒤 보강해야 합니다. 공지의 최신성, 이미지·영상 게시 권한, 운영 주체·보관기간·문의 수신·동의 설정도 확인이 필요합니다. [운영 확인 목록](adsense-operational-confirmations.md)에 항목별로 정리했습니다.

P0의 미검토 소개 비공개 기준과 광고 비활성 상태를 유지합니다. P1 코드 반영은 AdSense 승인이나 신청 준비 완료를 의미하지 않으며, 운영 자료 검토와 배포 후 확인이 남아 있습니다.
