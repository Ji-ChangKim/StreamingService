# 2026년 11월 13일 자동화 수정 배포와 실제 신규 채널 시험

**이 문서는 당시 배포·시험 결과를 보존합니다. 이후 Tavily 로컬 실검색은 [별도 시험 기록](tavily-pilot-2026-11-13.md), 앞으로의 구현·운영 기준은 [신규버튜버자동화 최종 계획](신규버튜버자동화.md)을 따릅니다. 아래 ‘선택 대기’는 이 배포 당시 상태이며, Tavily 서버 연결은 여전히 미완료입니다.**

**완료:** 신규 발굴 예산 분리, 서버 CSV 선저장·재읽기, DB 중복·충돌 보호, 공개 프로필·달력 검증, CSV T 처리와 복구를 구현·배포했습니다. 기존 자료에 없던 **슈리리_**로 실제 공개까지 확인했습니다.

**선택 대기:** 범용 키워드 검색 서비스입니다. 공급자·사용 조건을 비교하기 전 가입을 요청한 순서는 잘못이었습니다. 검색 서비스는 활성화하지 않았고 [도입 검토](search-service-review-2026-11-13.md)를 별도로 작성했습니다. 전체 웹 검색 연결까지 완료된 상태로 보고하지 않습니다.

| 달력 운영 코드 | `PLATFORM_DEBUT`를 `FIRST_DEBUT`로 바꾸던 실제 운영 변환과 편집 시 유형 손실 수정 |

## 4. 검증

- 자동화·포털·CSV·보고·조사 관련 **189개 시험 통과**.
- 수집기 TypeScript 검사·공식 환경 타입 재생성·배포 전 번들 확인 통과.
- 현재 공개 442개 프로필로 운영 달력 변환 전후를 비교. 행사 유형·제목 이외의 행사 필드는 유지.
- 실제 공개 API·상세 URL HTTP 200, 이름·공식 이미지·방송국 URL 일치.
- 실제 프런트엔드의 `buildCalendarIndex`로 한국 활동권역·한국시간 11월 21일 노출 확인.
- 기존 441명 공개 프로필 JSON 전체 동일, 새 채널 공개 이력 정확히 1건.

- 브라우저를 직접 조작하는 육안 UI 검사는 수행하지 않았습니다. 기존 화면 파일을 배포한 작업도 아닙니다.

## 7. 남은 범위

현재 남은 것은 **어떤 검색 서비스를 어떤 사용 조건으로 붙일지 결정하고, 그 서비스의 실제 이름 없는 검색 성능을 시험하는 일**입니다. Tavily를 선택한다면 현재 Naver 시험 연결부와 별도로 Tavily 연결을 구현해야 합니다. 계정·카드·유료 호출·외부 문의는 진행하지 않았습니다.

고정 공개 원천의 자동 수집·CSV·등록 경로가 동작한다는 사실과 범용 웹 검색까지 완성됐다는 주장을 구분합니다. 검색 공급자를 결정하기 전에는 키만 발급하면 전체 작업이 끝난다고 설명하지 않습니다.
