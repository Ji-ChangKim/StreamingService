## 콘텐츠 재검토

2026년 10월 15일 대상 9개 페이지를 공식 채널·본인 게시글과 대조했습니다. 페이지별 수정 문구와 확인 범위는 [P0 콘텐츠 9개 페이지 검토안](adsense-p0-content-review.md)을 참고하세요. 星存なのか는 첫 방송 자료·날짜, 江口真好는 소속·현재 활동 상태까지 추가 정정 검토가 필요합니다. 이번 검토안으로 공개 승인이나 운영 자료 변경을 실행하지는 않았습니다.

- 기존 자료에는 새로운 콘텐츠 검토 기록이 없으므로 배포 시 공개 목록에서 제외됩니다. 원본을 삭제하거나 일괄 승인하지 않았습니다.
- `/admin?view=portal`에서 로그인 후 `콘텐츠 검토·공개 관리`로 진입합니다. 활동명·소속·일정의 공식 출처, 이미지·영상과 소개 내용, 게시 권한을 확인하고 정정합니다.
- 원문이 영상 제목으로 들어간 사례: `/creator/hoshiari-nanoka`, `/creator/kinamochi-kina`. 실제 활동명은 공식 채널을 대조한 뒤 운영자가 입력해야 합니다.
- 성인 지향 소개와 소속 불일치가 관찰된 사례: `/creator/eguchi-maho`. 단어만 순화해 다시 게시하지 말고 원본 콘텐츠의 성격과 실제 소속을 검토해야 합니다.
- 한국어·일본어·영어 자료를 동일하게 검토합니다. 자동 표현 탐지는 일부 신호를 찾는 보조 수단이며, 이미지·영상·문맥·저작권 심사를 대신하지 않습니다.
- 내용이 같은 URL의 외부 이미지·영상은 나중에 변경될 수 있습니다. 저장 주소의 승인 기록만으로 미래의 원격 미디어 내용까지 보증할 수 없으므로 정기 재검토와 필요 시 자체 보관 정책을 마련해야 합니다.
- 방송 통계의 제목은 제한된 의심 표현을 중립 안내로 바꿉니다. 모든 부적절한 제목을 탐지하는 기능이 아니므로 광고는 계속 비활성 상태로 유지해야 합니다.

## 배포 순서

1. 개발 환경에 코드를 반영하고 기존 자료의 관리자 조회가 유지되는지 확인합니다.
2. 핵심 소개를 실제 자료에 근거해 검토합니다. 운영 환경에서도 해당 검토 기록이 필요하며 개발 DB의 승인 기록이 자동으로 운영 DB에 반영되는 것은 아닙니다.
3. 운영 환경의 기존 자료가 검토 완료 전까지 비공개가 되는 영향을 확인하고 배포 및 검토 작업 순서를 정합니다. 검토 없이 기존 자료를 공개하는 우회 설정은 추가하지 않았습니다.
4. 운영 정보와 보관·동의 설정을 확정한 뒤 정책을 완성합니다. 현재 개인정보 안내는 확인 가능한 코드 동작만 반영한 상태로, 최종 운영 정보 검토가 남아 있습니다.
5. P1 메인 안내·소개 구성·이용 가이드·통계 해설은 코드에 반영했습니다. 운영 배포 후 실제 승인된 대표 소개의 내용과 크롤러 접근을 확인하고 신청합니다.

## P1 콘텐츠 확인 사항

| 항목 | 코드에 반영한 내용 | 운영자가 확인할 내용 |
| --- | --- | --- |
| 개별 버튜버 소개 | 저장된 소개 원문, 콘텐츠 태그와 방송 언어만 표시 | 실제 주력 콘텐츠, 방송 언어, 첫 방송 계획이 빠진 소개는 당사자 또는 공식 채널에 확인한 뒤 보강 |
| 공지 출처 | 등록된 공지 주소만 연결 | 공지의 실제 접근 가능 여부, 변경·취소 여부, 원문과 등록 일정의 일치 |
| 소개 검토일 | 저장된 승인 검토일을 KST 날짜로 표시 | 최신 공지 확인일이나 당사자 인터뷰일을 의미하지 않음. 운영 검토 절차와 실제 기록 관리 필요 |
| 주간 안내 | 공개된 등록 일정의 날짜·플랫폼·입력된 한 줄 소개로 구성 | 주간 뉴스·인터뷰·추천 사유는 생성하지 않음. 운영 편집 글을 추가하려면 취재 자료와 출처 확보 |
| 방송 통계 | 실제 조회 범위·기록 수와 집계 해설 표시 | 운영 수집 상태와 누락 원인, 외부 플랫폼 전체를 포괄하는지 여부는 별도 확인. 신규 등록·활동 상태를 빈 기록만으로 판단하지 않음 |
| 가이드 글 | 현재 기능에 근거한 저장·시간대·소개 작성·일정 변경·통계 안내 5편 | 실제 사용 환경의 캘린더 가져오기와 대표 등록·정정 사례를 배포 후 확인 |

P1은 화면과 안내 콘텐츠를 보강한 작업입니다. 개별 소개의 사실 확인, 운영 정보 확정, 실제 콘텐츠 승인을 대신하지 않습니다. 자세한 수정·검증 기록은 [P1 반영 보고서](adsense-p1-report.md)를 참고하세요.

## P2 배포 후 확인 사항

| 항목 | 코드로 확인한 범위 | 운영자가 확인할 내용 |
| --- | --- | --- |
| 운영 Worker·정적 파일 연결 | `PORTAL_ENABLED=true`인 로컬 Worker의 동적 HTML·사이트맵·robots | 실제 운영 플래그, 라우트·도메인 연결, 정적 파일 우회 배포 여부와 캐시 갱신 |
| canonical·검색 설명 | 서버·브라우저의 대표 주소와 페이지별 설명 일치 | 배포된 대표 소개의 실제 응답, Search Console의 Google 선택 canonical과 색인 상태 |
| 사이트맵 | 승인 소개·언어별 URL·중복 제거·확인 가능한 수정일만 사용 | 운영 DB의 승인 상태, 실제 사이트맵 제출·읽기 결과와 포함 URL 접근 |
| robots·크롤러 | 공개 페이지 허용, 개발 Worker 전체 차단, 로컬 사용자 에이전트 요청 검증 | Googlebot·Mediapartners-Google·Google-Display-Ads-Bot의 실제 접근 로그, WAF·봇 방어·로그인·지역 제한 |
| 개발·대체 호스트 | 개발 Worker의 noindex·robots 차단 | 개발 호스트를 Worker 없이 정적 파일로 따로 제공하는지, 별도 호스트·미리보기 주소의 검색 제한 |
| 오류·빈 화면 | 메모리 DB·로컬 API에서 404·503·빈 목록·손상 응답·재시도 검증 | 운영 장애 복구, 실제 문의 수신, 접수 상태 조회와 주요 링크의 정상 동작 |
| 모바일 | 320px·390px 브라우저에서 탐색·입력·상세 창·하단 여백 확인 | 실제 iOS·Android 키보드, 화면 확대, 노치·안전 영역, 보조 기술과 긴 실제 소개 |
| 광고 | 광고 전역 비활성 유지, 확인한 화면의 광고 요소 0개 | 실제 배포에 이전 광고 코드나 태그가 남았는지 확인. 게시자·동의·콘텐츠 확인 전까지 활성화하지 않음 |

P2에서는 운영 계정 설정, 실제 Google 색인·크롤러 접근, 외부 통계 수집 정상 여부를 대신 확정하지 않았습니다. [P2 수정·검증 보고서](adsense-p2-report.md)를 함께 확인하세요.

이번 최종 작업에서는 개발 Worker·자산만 배포하고 원격 개발 DB는 SELECT로만 확인했습니다. 운영 배포, 원격 DB 변경·마이그레이션, AdSense 신청, 실제 콘텐츠 승인, 외부 알림 발송은 수행하지 않았습니다.
