# 버튜버 발굴 서버 자동화 운영 기록

현재 기준은 [신규버튜버자동화 최종 계획](신규버튜버자동화.md)입니다. 11월 13일 후속 [CSV·예산 분리 배포](debut-pipeline-release-2026-11-13.md)와 [Tavily 실검색](tavily-pilot-2026-11-13.md)을 구분해 봅니다. 아래 11월 12일의 ‘최신·추가 구현 대상’ 표기는 당시 기록이며 현재 상태가 아닙니다.

> 문서 안내: [전체 자료](debut-automation-documents.md) · [11월 12일 작업 정리](work-summary-2026-11-12.md) · [최신 기술 기준](신규버튜버자동화.md). 아래는 당시 배포·시험 이력입니다. CSV 선저장 경로는 추가 구현 대상이며, 소속사 출처 일괄 보류는 수정할 코드 결함입니다.

2026-11-12 추가 실증: [신인 발굴·프로필 보강 검증 보고서](debut-discovery-audit-2026-11-12.md). 최신 정식 버전은 `088bd9d7-08e6-4eb2-9a53-c9e2e1fc6eca`다. 아래 초기 7명 공개는 기존 조사 후보 등록 실적이다. 추가 시험에서 기존 자료에 없던 치지직 채널 2명을 후보로 식별·보존했으나 일시·첫 활동 범위 미확정으로 공개하지 않았다. 기존 11월 1~11일 등록자 36명을 검사해 8명·12항목을 보강했다. 치지직 전체 신인의 발굴·일정 공개까지 완료했다는 뜻은 아니다.

최신 수집 경로에는 카론 유니버스 공식 공지 목록과 레버니아 공식 X 계정이 추가됐다. 레버니아 홈페이지의 Cloudflare HTTP 406 실패는 기록으로 남기고 정기 조회 대상에서 제외했다. SOOP 실제 소개 필드와 본인 작성 프로필 글을 읽으며, 날짜 없는 후보는 최초 발견일을 기준으로 보관한다. 시간 미정 소개도 일정 상태를 보존하며 제원을 보강한다. 비용 상한은 유지했고 시험용 분 단위 예약은 제거했다.

2026-11-12. 담당 Worker: `vdebut-discovery`. 운영 DB: 기존 `vdebut-db`.

구현·운영 배포·실제 서버 예약 시험 및 PC 예약 중지를 완료했다. 조사 범위와 남은 한계는 아래에서 구분한다.

## 언제 무엇을 조사하는가

| 한국시간 | 대상 기간 | 작업 |
| --- | --- | --- |
| 매일 09:00 | 7일 전~30일 후 | 공식 일정·공개 시트·데뷔 공지 계정에서 후보 발견, 공식 채널과 원문 검증, 조건을 통과한 신규 프로필·일정 공개 |
| 매일 21:00 | 같은 기간, 오늘~3일 후 우선 | 임박 일정·채널·프로필 이미지와 변경 공지 재확인. 오전 대기열 이어서 처리 |
| 월요일 10:00 | 30일 전~90일 후 | 금주 누락 점검, 전주 데뷔자의 명시된 캐릭터 정보 보강, 31~90일 후 일정은 후보로 확보 |

Cloudflare 예약식은 UTC 기준 `0 0 * * *`, `0 12 * * *`, `0 1 * * MON`이다. 날짜 계산은 서버 위치와 관계없이 Asia/Seoul 기준이다. 조사가 끝나지 않으면 다음 회차에서 대기열을 이어서 처리한다. 일정이 지났다는 이유로 방송 완료를 확정하지 않는다.

## 원천과 실제 수집 범위

- SOOP: <https://welcomevirtual.sooplive.com/>의 공개 일정 응답. `api/api.php?work=getScheduleList&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD`에서 기간 내 전체 목록을 읽는다. 공식 사이트 내부 응답이며 정식 상업용 개발자 API라는 의미는 아니다.
- 공개 시트: 기존에 연결된 `1SEcOZAhMqFLUW7bxSsBkWK0UriMD3fD82xXX2HrUf38`, `gid=1884409648`의 공개 CSV. 후보 발견에 사용하며 원문 확인을 대신하지 않는다.
- X 공지 계정: `VtuberDebutBot`, `KRVtubefollower`, `vvw_kr`의 공개 페이지에서 게시물 링크를 발견하고 별도 원문 대기열에 저장한다. 회차당 원문 2개까지 추가 확인한다. 재게시의 날짜·방송국을 그대로 확정하지 않는다.
- SOOP 채널: `https://chapi.sooplive.co.kr/api/{고유ID}/station`. 현재 활동명은 `user_nick`, 이미지는 공식 `profile_image`를 사용한다.
- 치지직 채널: `https://api.chzzk.naver.com/service/v1/channels/{고유ID}`. 채널 ID·현재 이름·공식 이미지·공개 소개를 대조한다. `firstBroadcastDate`의 누락은 최초 활동의 증거로 사용하지 않는다.

Cloudflare에는 대화의 웹 검색 도구가 없다. 이 수집기는 공개 원천의 변경을 조회하는 방식이며 X 전체 검색·치지직 전 채널 검색·전체 채팅 수집을 하지 않는다. X의 접근 제한이나 본문 생략은 실패·보류로 남긴다. 시트나 공개 공지에 없는 모든 치지직 신인을 발견한다고 보장하지 않는다. X 유료 API, SSAPI, 유료 검색, AI, 브라우저 실행은 연결하지 않았다.

## 검증과 공개

1. 후보의 발견 원천·고유 채널·행사 종류·일시·시간대·원문 URL을 D1 대기열에 저장한다.
2. 공식 채널 응답의 ID·이름·이미지를 확인한다. 프로필 이미지의 허용 CDN, 2 MiB 크기 제한, 래스터 파일 헤더·크기·픽셀 규격을 확인하고 이미지 해시를 기록한다.
3. SOOP `debut`은 **SOOP 플랫폼 데뷔**로 공개한다. `transfer`는 첫 데뷔로 공개하지 않는다. 치지직 새 공지는 작성자·본문의 방송국 연결·행사 범위·날짜·시각·시간대를 확인할 수 있어야 한다. 원문이 짧아 불확실하면 보류한다.
4. 본문·현재 채널 소개의 의심 표현, 공개 정책, 기존 프로필·보조 채널·검토 대기와의 중복을 확인한다. 텍스트는 사실 안내용 공통 문장만 생성한다. 소속·국적·캐릭터 제원을 추정하지 않는다. `countryCode=KR`은 한국 활동권역이며 국적 인증이 아니다.
5. 프로필·채널 색인·변경 이력을 한 번의 D1 원자적 묶음으로 저장한다. 운영자 수정과 겹치면 저장하지 않는다. 본인 소유권 인증은 자동 부여하지 않는다.
6. 공개 프로필 API와 실제 달력 API를 운영 Worker 내부 연결로 다시 읽는다. 이름·이미지 URL·방송국·행사 종류·한국시간 날짜·활동권역이 저장값과 일치한 경우에만 `PUBLIC_VERIFIED`로 기록한다. 저장만 되고 공개 확인이 실패하면 `PUBLISHED_PENDING_CHECK`로 남긴다.

이미지 검증은 공식 출처와 파일의 기술적 유효성 검사다. AI 시각 분석이나 사람의 화상 검토를 수행했다는 뜻이 아니다. 의심 텍스트·이미지 오류·소유 관계 모호·충돌은 자동 공개 대상에서 제외한다. 공식 공지에 확인된 항목만 보강하며, 다른 소개글에 등장한 단어나 생일을 근거로 종족·별자리를 추정하지 않는다.

기존에 운영자가 관리한 프로필은 공식 이름·이미지·일정이 모두 일치할 때에만 자동 관리 기준값으로 연결한다. 그 뒤 운영자가 JSON을 수정하면 자동 갱신을 보류한다. 운영자가 삭제한 소개의 재생성과 다른 대표 프로필의 보조 채널 일정 덮어쓰기도 막는다. 같은 정보는 프로필과 수정 이력을 재저장하지 않는다. 공식 일정 목록에서 사라졌다는 이유만으로 공개 정보를 삭제하지 않는다. 연기·취소 등 행사 범위가 모호한 변경은 보류하므로, 모든 취소 공지가 자동으로 달력에서 제거되는 것은 아니다.

전주에 이미 공개된 채널의 빈 제원을 보강할 때에는 기존 데뷔 유형·일정을 그대로 두고 공식 소개의 명시된 항목만 추가한다. 첫 데뷔 공지를 새로 확인하지 않은 보강 기록에는 `scheduleReconfirmed=false`를 남긴다. 주간 원천을 별도 보관해 적재 상한을 넘긴 후보도 다음 일일 회차에서 이어서 저장한다.

## 비용과 실행량 상한

| 항목 | 적용 기준 |
| --- | --- |
| 정기 실행 | 월 최대 70회. 실행 전에 월 사용량 예약, 슬롯 고유키·전역 임대·저장 시 임대 소유권 재확인 |
| 상세 확인 | 일일 회차 최대 20명, 주간 회차 최대 10명 |
| 외부 조회 | 회차당 최대 40회. 리디렉션도 포함. 동시 외부 조회 최대 3개 |
| 추가 공지 원문 | 회차당 최대 2개. 미확인 링크는 대기열 보관 |
| CPU | Cloudflare 설정 `cpu_ms=5000` |
| 전체 하위 요청 | Cloudflare 설정 `subrequests=400`. 외부 40회 제한과 별개로 DB·사이트 내부 조회도 포함 |
| 응답 | 원천·이미지 2 MiB, 공개 응답 4 MiB. 무제한 본문 누적 금지 |
| 시간 | 외부 조사 단계 105초, 공개 응답 각각 15초 제한. 남은 후보는 넘김 |
| D1 | 회차당 문장 220개. 읽기 3만·쓰기 700행 기준에 여유를 두고 추가 조사 중단 |
| 보관 | 실행 기록 90일, 조사 후보 180일 이후 소량 정리. 기존 공개 프로필·운영자 이력은 삭제하지 않음 |

정상 일정은 31일·월요일 5번인 달에 최대 67회다. 월 70회 상한은 초기 배포 시험도 포함한다. 이번 초기 시험은 오류 수정 재시험을 포함해 최대 12회이며, 시험 종료 뒤 분 단위 예약과 시험 허용 시각을 제거한다. 최초 전환일이 11월 12일이어서 11월 남은 정기 실행을 포함해 70회 안에 운영할 수 있다.

최대 예약량은 월 외부 2,800회, 조사 CPU 350,000ms다. D1 행 수는 실제 결과 메타정보를 관측해 중단하므로 DB의 강제 청구 한도와는 다르다. 마지막 쿼리·인덱스·마감 기록·공개 사이트 내부 확인의 사용량은 추가될 수 있다. 실행 로그의 DB 집계는 조사 Worker의 직접 쿼리 기준이다.

추가 비용 관리 목표는 월 US$1 이내이며 **계정 전체의 달러 청구 차단 장치가 아니다**. 기존 유료 Workers 요금제와 포함량의 잔여분을 함께 사용한다. 포함량 안이면 이 기능의 추가 사용료가 없을 수 있으며, 신규 Workers 유료 플랜의 월 기본요금은 별도다. 다른 사이트 기능의 트래픽·DB 비용까지 이 수집기가 제한하지 않는다.

요금 근거: [Workers](https://developers.cloudflare.com/workers/platform/pricing/), [D1](https://developers.cloudflare.com/d1/platform/pricing/). 현재 DB는 초기 확인 시 약 0.91GB였으며 새 DB·이미지 저장소·유료 외부 API를 만들지 않았다.

## 운영 확인과 중지

설정은 `backend/wrangler.debut-automation.jsonc`, 변경 테이블은 `0063_debut_server_automation.sql`이다. 기존 마이그레이션 일괄 실행은 하지 않는다.

최근 실행은 다음 읽기 쿼리로 확인한다.

```sql
SELECT slot,status,started_at,finished_at,summary
FROM debut_automation_runs ORDER BY started_at DESC LIMIT 5;
SELECT id,status,checked_at,last_success_at,failures,reason
FROM debut_automation_sources;
SELECT id,status,reason,profile_slug,next_check_at
FROM debut_automation_candidates WHERE status IN ('HOLD','FAILED','PUBLISHED_PENDING_CHECK');
```

긴급 중지는 다음 한 행으로 외부 조회와 자동 반영을 막는다. 이미 시작한 작업도 저장 직전에 `enabled`를 다시 확인한다.

```sql
UPDATE debut_automation_control SET enabled=0 WHERE id='discovery';
```

서버 D1의 후보·근거·실행 이력이 무인 운영의 정본이다. PC의 월별 CSV는 기존 작성일과 T/F를 보존한 스냅샷으로 유지한다. 서버가 PC의 로컬 CSV를 직접 갱신한다고 설명하지 않는다. CSV를 추후 내보낼 때도 공개 반영 확인 없이 T로 바꾸지 않는다.
