## 주요 흐름

Cloudflare 정기 실행 → 실행 중복·비용 한도 확인 → 원천 조회 → 후보 저장·기존 등록 대조 → 검증 또는 보류 → 변경된 정보만 원자적 저장 → 공개 프로필·방송국·캘린더 재확인.

- 매일 한국시간 09시·21시. 월요일 10시에는 조사 범위를 확대하고 전주 등록자 보강 대상을 추가한다.
- 일반 범위는 7일 전~30일 후, 월요일 범위는 30일 전~90일 후다. 31~90일 후 일정은 후보만 확보한다.
- 현재 소속사 발굴 후보는 `AGENCY_NOTICE` 경로에서 보류된다. 후보 발견에서 일시·행사 범위 확정 및 자동 공개로 넘어가는 연결은 아직 구현되지 않았다.
- 기존 프로필 보강은 공식 채널·본인 프로필 글에서 확인한 빈 값만 추가한다. 기존 값·데뷔 일정·시간 미정 상태를 보존한다.
- 검증 실패·운영자 수정 충돌은 보류, 변경 없음은 재저장 생략, 조회량 한도 도달은 대기열을 다음 회차로 넘긴다.
- 저장 후 공개 확인에 실패하면 `PUBLISHED_PENDING_CHECK`로 남긴다. `PUBLIC_VERIFIED`와 구분한다.

운영 재대조 시각은 2026-11-12 17:19 KST다. 처음 공개 조회는 제한 시간에 걸려 재시도했으며 최종 프로필·캘린더는 HTTP 200이었다. 현재 공개 프로필은 435명이다.

이번 테스트는 코드 분기 재시험과 운영 데이터의 읽기 대조다. 직전 실제 Cloudflare 조사 시험은 11월 12일 15:30 KST이며, 이번 요청에서 새로운 조사 회차를 강제로 실행하거나 운영 데이터를 수정·재배포하지 않았다. 전체 백엔드 빌드는 기존 `weeklySpecResearchService`의 `computeWikiDiffs` 가져오기 오류가 있어 통과로 보고하지 않는다.

## 비용과 남은 범위

정규 예약은 매일 09시·21시와 월요일 10시다. PC 예약 중지 상태를 유지한다. 새 유료 외부 서비스를 추가하지 않았고 실행량 제한을 유지했다. 이 제한은 계정 전체의 달러 청구 차단 장치가 아니다.

치지직 전체 신인을 빠짐없이 찾는 기능과 소속사 후보의 본인 공지·행사 범위·시간대 자동 확정은 남아 있다. 이미지 검사는 공식 출처·파일의 기술적 검사이며 시각 검수를 뜻하지 않는다.
