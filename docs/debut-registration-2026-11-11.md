## 출처와 등록 범위

- 일정: SOOP 공식 웰컴버추얼 캘린더의 해당 기간 `debut` 항목. 채널: 공식 방송국의 고유 user_id. 이름·이미지: 공식 방송국 응답의 user_nick·profile_image. 본인 공지 출처는 [조사 보고서](../vtuber-list/2026-11/research-test-2026-11-11_14.md)에 있다.
- ‘SOOP 데뷔 일정’으로 등록했다. 최초 활동 범위를 보류했던 4명도 사용자가 요청한 플랫폼 데뷔 일정·채널·공식 이미지가 확인되어 공개했다. 모든 플랫폼을 통틀어 생애 첫 버튜버 활동이라고 새로 확정한 것은 아니다. 기존 일정 구조의 행사 유형은 FIRST_DEBUT이며, 별도 플랫폼 데뷔 유형을 추가하는 코드 변경은 하지 않았다.
- `countryCode=KR`은 한국 SOOP·한국어 본인 공지·KST 일정에 근거한 서비스의 활동권역이다. 국적 정보가 아니다. 한국 활동권역 기본 달력에서 표시되는 것을 실제로 확인했다. 미확인 소속·X·연락처·캐릭터 제원은 채우지 않았고, 본인 소유권 인증은 false로 유지했다.
- 단온은 공식 방송국이 사용하는 프로필 이미지로 등록했다. 임의 캐릭터 이미지나 제작 리소스를 넣지 않았다.

## 저장·검증

- 운영 `vdebut-db`에서 공개 프로필, 채널 인덱스, 기존 방송 채널, 심사대기 중복을 먼저 조회했다. 대상 신규 5명은 중복·심사대기 없음. 꾼구마는 기존 JSON과 구형 방송 채널 레코드를 함께 정정했다.
- `0061_register_nov11_14_soop_debuts.sql`을 명시 실행해 신규 프로필·채널 인덱스 각 5건과 신규/정정 이력 6건을 저장했다. 이어 `0062_align_nov14_calendar_activity_regions.sql`로 기존 치지직 3명의 공란 활동권역을 KR로 정리하고 검토 스냅샷·이력 3건을 기록했다. 해당 3명은 기본 한국 필터에서 빠지고 있었으며, 방송국·이미지·일정은 바꾸지 않았다. 자동 조사·자동 승인·Discord 알림·메일 발송은 실행하지 않았다.
- 실제 공유 함수로 공개 검토 스냅샷, 채널 ID, 날짜/시각의 KST→UTC 변환, 캘린더 날짜 색인, 이벤트의 방송 링크·이미지 일치를 검증했다.
- 운영과 동일한 테이블 정의로 실제 SQL의 재실행 멱등성, 심사대기 채널 보호, 현재값 충돌 시 기존 프로필 보호를 확인했다.
- 0061 운영 DB 재조회: 대상 프로필 6건·채널 인덱스 6건·이번 이력 6건 일치. 0062 후 공개 응답이 승인한 3명의 JSON과 일치했다. 최종 공개 API: 프로필·캘린더 각각 423→428건. 이름 정정 1명·활동권역 정정 3명을 제외한 기존 공개 프로필 419명의 값이 모두 동일했다.
- 신규 5명의 공식 이미지 URL에서 이미지 파일을 정상 수신·디코딩하고 내용을 확인했다. 실제 브라우저에서 5명 상세 페이지의 이름·시각·SOOP 링크와 달력의 11/11·12·14 일정 노출을 확인했다. 11/11 더 보기에는 우디디디·꾼구마·수지AI·단온의 상세 링크와 방송국 링크가 함께 표시되었다.
- 화면·하이라이트·캘린더·Header·Footer 코드는 수정하거나 배포하지 않았다. 빌드·전체 코드 테스트는 데이터 반영 작업이므로 실행하지 않았다.
- 월별 CSV의 최초 작성일을 보존하고 실제 등록을 확인한 행만 T로 갱신했다. 신규 등록 CSV 37행, 수정 제안 35행, 조사 기록 90행. BOM·CRLF·13/14/26열·고유 후보 ID·채널 중복을 검증했다.
- 기존 신규 등록 CSV에서 아먕·레오 퍄코·코바야시 후토·리즐 4행이 헤더와 다른 열 순서로 저장되어 있던 것을 발견했다. 실제 공개 프로필의 채널 ID로 대조해 올바른 열에 복구하고 최초 작성일과 T를 보존했다. 이 복구를 위해 리즐의 운영 프로필을 변경하지는 않았다. 날짜·시각·플랫폼·URL의 값 형식까지 추가 검증했다.
