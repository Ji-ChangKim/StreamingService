# AdSense 신청 준비 상태 재점검

2026년 10월 16일 KST 기준으로 **신청 보류를 권고한다.** 표기·레이아웃·기존 정정 배포는 완료했지만, 정보가 부족한 개별 소개, 성인용 태그를 포함한 추가 검토 대상과 운영 고지의 미완료 항목이 남아 있다. 공개 API의 Googlebot 접근 제한도 보완·검증 대상이다. Google의 실제 승인·거절 결과를 예측하거나 합격률을 계산한 판단은 아니다.

사용자의 목적은 홈페이지에 광고를 달아 수익화하는 것이므로 Google Ads 광고주 심사가 아닌 **Google AdSense 게시자 사이트 검토**를 기준으로 분석했다. 이번 작업은 읽기 전용 점검이며 코드·운영 DB·광고 설정·배포를 변경하지 않았다.

## 점검 범위와 근거

- 운영 공개 API의 소개 377건 전체 텍스트와 주요 필드, 주요 19개 경로의 응답과 초기 HTML, robots.txt·사이트맵, 크롤러 사용자 에이전트 3종 응답을 확인했다.
- 실제 브라우저에서 개인정보처리방침, 추가 태그 검토 대상 2개, 이름만 있는 소개, 모바일 통계와 해설 열기를 확인했다.
- 이미지·영상 전체를 시청하거나 게시 허락·계약서를 검증한 결과는 아니다. AdSense·Search Console 계정 내부 상태와 실제 문의 수신도 공개 응답으로 확정할 수 없다.
- 공개 API 집계 시각은 2026-10-16 00:46 KST이며, 실시간 통계는 확인 중에도 갱신된다.

Google은 고유하고 유용한 콘텐츠와 탐색 편의성을 요구하고, 가치 추가 없는 복사·삽입·재작성 콘텐츠를 제한한다. 사이트 기능이 제공하는 가치도 평가 대상이므로 블로그 글 수나 임의의 최소 글자 수를 승인 조건으로 삼지 않았다. [사이트 준비 기준](https://support.google.com/adsense/answer/7299563?hl=ko), [복제 콘텐츠 정책](https://support.google.com/publisherpolicies/answer/11190248?hl=ko).

### 크롤러가 보는 화면

- 운영 robots.txt의 `User-agent: *`와 `Disallow: /api/`는 Googlebot이 React의 목록·상세 조회 경로 `/api/v1/portal/profiles?version=3`를 수집하는 데 제약이 된다.
- `/creators` 초기 HTML에는 소개 카드 목록이 없으며, 개인정보처리방침·약관·서비스 소개도 초기 HTML에는 전문이 없다. 브라우저에서 JavaScript를 실행하면 정책 본문은 나타나지만, 초기 HTML 제공 범위를 넓히는 것이 크롤러 접근의 불확실성을 줄인다.
- 상세 소개와 가이드, 통계에는 일부 초기 본문이 제공된다. 모든 경로가 빈 화면인 것은 아니다.
- Googlebot·Mediapartners-Google·Google-Display-Ads-Bot 이름을 넣은 직접 HTTP 요청은 200이었다. 이 테스트는 실제 Google의 IP·robots 준수·JavaScript 렌더링을 검증하지 않으므로 실제 심사 크롤러 접근 성공과 동일하게 취급하지 않았다.

공개 API 접근과 서버 본문을 보완한 후 실제 URL 검사로 검증할 것을 권고한다. 이 진단은 Google Search 렌더링 문서와 현재 구조를 대조한 기술적 위험 판단이다. Google은 광고가 게재되는 페이지에서 AdSense 크롤러가 `User-agent: *` 차단에도 접근하는 예외를 설명하므로, 현재 규칙을 AdSense 전체 차단으로 단정하지 않는다. 실제 심사 크롤러 실패 로그를 확보한 것은 아니다. [JavaScript SEO 기본사항](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics?hl=ko), [AdSense 크롤러의 동작과 예외](https://support.google.com/adsense/answer/99376?hl=ko).

## 양호한 부분과 후속 확인

- 메인·목록·소개·가이드·정책·문의·통계 등 정상 경로는 HTTP 200이었다. 江口真好와 존재하지 않는 경로는 404·noindex를 유지한다.
- 확인한 대표 URL의 canonical은 운영 주소와 일치한다. 관리·관심 목록은 noindex이며 개발 도메인 robots.txt는 전체 차단을 유지한다.
- 사이트맵은 3,001개 URL이다. 소개는 377건의 언어별 1,131개 주소이고, 통계는 1,843개 주소다. 수집 기록이 있는 통계 채널을 포함하는 구조다. 사이트맵이 있다는 사실만으로 색인·승인을 보장하지 않는다.
- 가이드 5편과 통계 해설, 날짜·플랫폼별 조회 기능은 사이트의 고유한 실용 가치다.
- 00:46 KST에 받은 기본 7일 통계에는 활동 채널 1,470개·방송 4,292회가 집계됐고 마지막 기록 시각은 00:40 KST였다. 실시간 변동값이며 일부 수집 누락 표시를 유지한다.
- 모바일 통계는 가로 넘침 없이 표시되고 통계 해설 열기도 작동했다. 이번에 관측한 광고 요소는 없으며 전역 광고 비활성 상태를 유지한다. 실제 기기 전체 성능·Core Web Vitals 측정 결과는 아니다.

## 운영자가 직접 확인할 사항

1. AdSense 계정에서 `vdebut.live`의 소유 확인과 검토 요청 가능 상태를 확인한다. 현재 공개 HTML에는 AdSense 계정 메타 태그·광고 스크립트가 없고 ads.txt는 404다. 다만 Search Console 소유 확인으로 연결되는 경우도 있어 이 사실만으로 계정 연결 실패를 확정할 수 없다. 광고를 켜지 않고 실제 게시자 ID 메타 태그로 연결하는 방법도 있다. [사이트 연결](https://support.google.com/adsense/answer/7584263?hl=ko), [대체 소유 확인 안내](https://support.google.com/adsense/answer/12176698?hl=ko).
2. `ru_0120@naver.com`의 실제 수신과 문의 접수·답변 절차를 확인한다.
3. 운영 주체·개인정보 연락 책임, 보관·삭제·백업 절차, GA 데이터 보존·동의 설정을 확정한다. 현재 광고 고지는 향후 안내하겠다는 수준이다. [개인정보 공개 정책](https://support.google.com/adsense/answer/10502938?hl=ko).
4. 제3자 이미지·소개·영상의 이용 권한을 확인한다. 공식 공개 자료라는 이유만으로 재게시 권한이 자동으로 생기지는 않는다.
5. 광고 활성화 전 EEA·영국·스위스 개인 맞춤 광고에 적용되는 인증 CMP·TCF 설정을 확인한다. 현재 광고 비활성 상태에서 CMP가 보이지 않는다는 이유만으로 신청이 반드시 불가능하다고 판정하지 않았다. [지역별 동의 요건](https://support.google.com/adsense/answer/13554116?hl=ko).
6. Search Console에서 메인·목록·소개·개인정보처리방침의 실제 렌더링과 차단 리소스, 운영 로그에서 Google 크롤러 접근을 확인한다.

## 신청 재판정 기준

추가 콘텐츠 검토 2건과 권리 확인을 처리하고, 이름만 있는 소개 및 주요 노출 상세의 정보 부족을 해소하며, 공개 조회 API와 정책 본문을 크롤러가 읽을 수 있는지 실제로 확인해야 한다. 운영 고지와 계정 소유 확인까지 확정한 뒤 신청을 재판정한다. 고정된 글 수·글자 수·대기 일수로 승인 준비 완료를 대신하지 않는다.

근거 파일은 `.cache/adsense-readiness-20261016/`에 있다. `summary.json`, `content-analysis.json`, `technical.json`, 공개 API 원자료, 정책·표본 소개·통계의 브라우저 본문과 확인 화면을 보관했다.
