# VDébut 서비스 UX 및 문구 작성 원칙

본 스킬은 VDébut 내 모든 화면의 UI 문구, 툴팁, 안내 텍스트 및 지표를 작성하거나 노출할 때 반드시 준수해야 하는 핵심 원칙입니다.

## 1. 개발자 문구 화면 노출 절대 금지
- **개발자·시스템 관점의 면책/방어성 문구 절대 금지**:
  - ❌ 금지 예시: *"이 수치는 관측값이며, 새로 방송하는 채널의 예상 시청자 수가 아닙니다."*
  - ❌ 금지 예시: *"내부 알고리즘 시뮬레이션 결과입니다."*
  - ❌ 금지 예시: *"DB에 캐시된 임시 데이터입니다."*
- 개발자나 기획자만 이해할 수 있는 기술적 용어나 시스템 면책용 문장을 화면에 노출하여 사용자를 혼란스럽게 하지 않는다.

## 2. 타깃층 중심의 서비스 문구 작성
- **핵심 타깃**: **신입 버튜버, 신입 버튜버 데뷔를 준비하는 크리에이터, 팬/시청자**
- **문구 작성 원칙**:
  - 타깃 사용자가 방송을 켜거나 데뷔 일정을 잡을 때 실질적으로 도움이 되는 실용적이고 직관적인 언어를 사용한다.
  - 지표의 의미를 설명할 때는 "사용자가 이 지표를 보고 무엇을 판단해야 하는가?"에 집중한다.
  - 💡 권장 예시: *"시청자가 특정 대형 방송에 쏠리지 않고 분산되어 있을수록 신규 방송의 유입 기회가 큽니다."*

## 3. 데이터 신뢰성 및 검증되지 않은 사항 노출 금지
- 검증되지 않은 가중치, 임의로 만든 '기회 점수(84.5점 등)', 근거 없는 성공 확률이나 최적 추천 시간 등은 절대 화면에 노출하지 않는다.
- 데이터는 항상 실제 API/DB에서 객관적으로 검증된 수치(동시시청자 수, LIVE 방송 수, 평균, 중앙값, 점유율 등)만 투명하고 담백하게 제공한다.
