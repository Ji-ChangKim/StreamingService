## 1. 이 페이지의 목적

> **플랫폼별 인터넷 방송의 실시간 규모와 변화를 한눈에 모니터링하고, 카테고리·방송·스트리머 랭킹을 통해 현재 트렌드와 관심 방송을 파악한다.**

첫 화면의 중심은 실시간 통계와 랭킹이다. 전체 현황 → 플랫폼·카테고리 선택 → 방송·스트리머 상세 → 개별 기록이라는 기존 상세 탐색도 이어진다.

이번 요구에 따라 기본 기획의 집계 대상은 **플랫폼 전체 인터넷 방송**이다. 버튜버만의 수치를 전체 플랫폼 통계로 표시하지 않는다. VDébut의 신입 버튜버·데뷔 준비생도 이 방송 환경을 참고할 수 있다.

| 목표 | 정보를 배치하는 이유 | 주요 영역 |
| --- | --- | --- |
| G-01 실시간 모니터링 | 지금 어느 플랫폼에 시청·방송·채팅이 모이는지 확인 | 추이, 플랫폼 랭킹, 합계 |
| G-02 트렌드 파악 | 어떤 콘텐츠·방송이 주목받는지 비교 | 카테고리·실시간 방송·최고 시청 랭킹 |
| G-03 상세 확인 | 순위의 실제 방송과 개인 활동을 이해 | 검색, 방송 목록, 스트리머·방송 상세 |
| G-04 신뢰·활용 | 비교 기준을 알고 동일 조건의 자료를 다시 확인 | 범위·시각·상태, 다운로드, 조건 복원 |

2026-09-17 사용자 요청에 따라 현재 노출 플랫폼은 **SOOP·치지직**이다. 트위치·씨미는 메뉴, 범례, 순위, 안내, 검색, 다운로드에서 숨긴다. 재노출은 별도 범위로 관리한다. 실제 제공 범위는 [개발 반영 결과](./03_DEV_반영결과.md)를 따른다.

## 3. 기본 진입 상태와 범위

- 전체 플랫폼, 전체 카테고리로 진입한다.
- 첫 차트는 최근 24시간의 시청자 추이를 표시한다. 현재 화면에서도 차트가 즉시 보인다.
- 지표 탭: 시청자 / 채널 / 채팅.
- 플랫폼 랭킹 기본 순서는 현재 시청자 수 내림차순이다.
- 카테고리·실시간 방송은 현재 기준, 최고 시청 랭킹은 최근 18시간 기준이다.
- 시간은 KST로 표시하며 날짜를 넘는 차트에는 날짜와 시각을 함께 표시한다.
- 차트 기간 변경은 차트에만 적용한다. 현재 랭킹과 최근 18시간 랭킹은 각각 기준을 유지한다.
- 추이의 과거 지점을 선택하면 별도의 “선택 시각 방송” 영역을 연다. 현재 랭킹을 과거 수치로 조용히 바꾸지 않는다.
- 플랫폼 선택은 해당 플랫폼 대시보드로 이동한다. 카테고리 선택은 현재 화면의 방송 목록을 좁힌다.

## 4. PC 레이아웃

VDébut의 기존 상단 헤더를 유지하고, 방송 통계 영역 안에서 수평 플랫폼 탐색을 제공한다. 레퍼런스의 왼쪽 사이드바는 별도 추가하지 않는다.

- 콘텐츠 최대 폭 1,280px. 12열 기준 상단 차트 8열 / 플랫폼 4열.
- 차트와 플랫폼 랭킹은 같은 행에서 높이를 맞춘다.
- 카테고리 랭킹은 전체 폭을 사용한다.
- 하단 실시간 방송 7열 / 최근 18시간 최고 5열. 비교 열이 많거나 폭이 부족하면 세로로 배치한다.
- 페이지 제목·검색·조건의 높이를 제한해 첫 화면부터 주요 그래프와 플랫폼 수치를 볼 수 있게 한다.
- 광고는 통계의 시선 흐름을 끊거나 데이터 위를 덮지 않는다.

## 5. 영역별 명세

| 영역 ID | 정보·동작 | 목적 |
| --- | --- | --- |
| D1-01 | 제목, 집계 범위·시각, 통합 검색, 다운로드 | 무엇을 보고 있는지 이해 |
| D1-02 | 전체·플랫폼 선택 | 비교 대상 변경 |
| D1-03 | 공지 한 줄, 장애 리포트 열기 | 데이터 상태 확인 |
| D1-04 | 지표 탭, 기간, 플랫폼별 시계열, 범례, 툴팁 | 규모와 시간 변화 비교 |
| D1-05 | 합계, 순위, 플랫폼, 현재 시청, 활성 채널, 오늘 최고 | 플랫폼별 현황 비교 |
| D1-06 | 순위, 카테고리·플랫폼, 현재 시청·점유율, 채널 수 | 콘텐츠 트렌드 파악 |
| D1-07 | 순위, 프로필·이름, 제목, 콘텐츠, 현재 시청·점유율, 시작 시각 | 실제 방송 탐색 |
| D1-08 | 방송/채널 전환, 최고 시청 수, 기록 시각, 방송 식별 | 최근 18시간의 최고 기록 비교 |
| D1-09 | 광고 표시가 있는 별도 슬롯 | 부가 영역 |

### 플랫폼 랭킹

- 합계는 비교 가능한 플랫폼의 같은 기준 수치만 사용한다.
- 기본은 현재 시청 순, 오늘 최고 순으로 전환할 수 있다.
- 오늘 최고는 오늘 00:00 KST부터 기준 시각까지의 플랫폼 시청 합계 최고값이다.
- 각 플랫폼의 최고값은 발생 시각이 다를 수 있으므로 더해서 전체 최고라고 표현하지 않는다.
- 플랫폼을 선택하면 D-02로 이동한다.

### 시계열 추이

- 세 지표에 맞춰 Y축 단위를 명시한다: 시청 수 / 활성 채널 수 / 채팅 메시지 수·분.
- 범례로 플랫폼의 선을 확인하고 차트에서 숨길 수 있다.
- 툴팁에는 시각과 같은 시각의 플랫폼별 값을 함께 표시한다.
- 미지원 지표는 “채팅 데이터 제공 없음”처럼 안내하며 0으로 그리지 않는다.
- 기간 선택에 따른 과거 상세는 기존 개인 기록 흐름과 연결한다.

### 카테고리 랭킹

- 기본은 시청 수 순이며 채널 수 순으로 전환한다.
- 플랫폼별 원본 카테고리를 플랫폼과 함께 구분한다.
- 플랫폼 간 같은 이름을 통합할 때에는 검증한 매핑만 사용한다.
- 전체 플랫폼에서는 플랫폼·카테고리 조합을 구분한다. 점유율은 현재 선택한 플랫폼 범위가 분모다.
- 카테고리 선택 시 실시간 방송 목록을 좁히고 조건 해제 버튼을 제공한다.
- 게임 펼치기와 세부 게임 검색은 플랫폼 분류가 계층 구조를 제공하는 경우에 유지한다.

### 실시간·최고 시청 랭킹

- 실시간 랭킹은 현재 시청 수 기준이다.
- 최고 시청 랭킹은 기준 시각 직전 18시간의 이동 구간을 사용한다.
- 최고 랭킹의 “방송” 모드에서는 방송 세션별, “채널” 모드에서는 채널별 18시간 내 최대 기록을 한 행씩 보여준다.
- 최고 기록은 방송 종료 후에도 18시간 창 안에 기록이 있으면 남는다.
- 카테고리가 바뀐 방송의 최고 기록에는 해당 최고 시각의 카테고리를 표시한다.
- 방송 보기와 스트리머 이름을 별도 동작으로 구분한다.

## 6. 검색·부가 영역

### U-01 통합 검색

- 결과를 스트리머 / 카테고리 두 그룹으로 나눈다.
- 등록된 SOOP·치지직 스트리머 전체와 현재 수집 방송·최근 18시간의 이름이 확인된 기록에서 이름을 검색한다. 플랫폼 전체 채널 검색을 의미하지 않는다.
- 검색 버튼·Enter로 결과를 열고 방향키·Enter 또는 클릭으로 선택한다. 띄어쓰기를 달리 입력해도 검색할 수 있다.
- 스트리머 선택 시 채널·VDébut 프로필 링크와 확인된 현재 방송·18시간 기록을 보여준다. 현재 수집 목록에 없다는 이유로 방송 종료로 단정하지 않는다.
- 등록 채널 결과는 최대 20개이며 더 있는 경우 검색어를 좁히도록 안내한다. 검색 중·실패·결과 없음·검색어 지우기를 제공한다.
- 카테고리는 해당 플랫폼·카테고리 조건을 적용한다.
- 동명이인, 같은 카테고리 이름을 플랫폼 표시로 구분한다.

### U-02 공지·장애 리포트

- 사용자에게 영향을 주는 공지가 있으면 제목·발생 시각을 한 줄로 표시한다.
- 상세에서 영향 플랫폼·지표·기간, 진행/해결 상태를 확인한다.
- 일반 공지와 현재 장애를 구분한다. 상세 열기 중 기존 필터를 잃지 않는다.

### U-03 데이터 다운로드

- 버튼명은 “데이터 다운로드”로 한다.
- 패널에서 플랫폼, 데이터 종류, 실제 포함 기간, 생성 시각을 확인한다.
- “전체 데이터”는 선택 범위의 전체 결과이며 화면에 보이는 상위 몇 행으로 제한하지 않는다.
- 서로 다른 기간의 자료는 별도 파일로 제공한다. 자세한 계약은 PRD를 따른다.

### 계정·광고

- 로그인·회원가입·광고 제거는 기존 계정·상품 기능이 있는 경우 그 기능에 연결하는 보조 액션이다.
- 계정과 광고 제거 결제 자체를 이번 통계 개발에서 새로 만드는 것으로 해석하지 않는다.
- 광고 슬롯은 실제 광고가 없을 때 비워 두며 예시 광고를 운영 화면에 넣지 않는다.

## 7. 개인·개별 방송 상세

C-01은 프로필·현재 상태 → 기간 선택·활동 요약 → 콘텐츠 → 방송 이력 → C-02 순서다.

C-02에는 선택한 방송의 제목·날짜·유효한 시작/종료 정보·시청 추이·콘텐츠 변경 구간·유효한 다시보기 연결을 제공한다. 기존 개인 페이지와 통합하며 채널 식별을 기준으로 연결한다.

검색과 모든 랭킹은 같은 채널의 동일 개인 상세를 사용한다. 방송 선택 시 해당 기록을 펼친다. 복귀 시 플랫폼·카테고리·지표·기간·정렬·선택 행·스크롤 위치를 복원한다.

## 8. 모바일·접근성

- 900px 미만에서는 상단을 플랫폼 요약 → 추이 순으로 쌓고 하단 두 랭킹도 세로 배치한다.
- 플랫폼 요약은 합계와 네 개의 짧은 행으로 압축한다.
- 카테고리는 2열, 작은 폭에서는 1열로 배치한다.
- 실시간 방송은 이름·제목·시청 수를 우선 표시하고 나머지 필드는 펼쳐 확인한다.
- 검색과 다운로드를 모바일에서도 유지한다.
- 320px·390px에서 가로 잘림 없이 지표 전환·필터·검색·상세·복귀가 가능해야 한다.
- 모든 탭·필터는 키보드 조작, 명확한 이름과 선택 상태를 제공한다.

## 9. VDébut 디자인 적용

| 요소 | 적용 |
| --- | --- |
| 브랜드 헤더 | 기존 로고·데뷔 일정·방송 통계 구조 유지 |
| 배경 | 기존 밝은 회청색 #F8FAFC |
| 카드 | 흰색, 얇은 #E2E8F0 경계, 12~16px 모서리 |

| 본문·보조 | #475569 / #64748B, 충분한 대비 |
| 정보 밀도 | 짧은 제목·조밀한 순위 행, 긴 소개와 과도한 KPI 중복 배제 |
| 플랫폼 구분 | 공식 원본 로고와 이름. 로고 색상·배경을 임의 가공하지 않음 |
| 랭킹 강조 | 순위·숫자·작은 막대 중심. 큰 색 면적으로 정보 구분을 대신하지 않음 |

## 10. IA 수용 기준

- 첫 화면에 차트와 플랫폼 랭킹이 함께 보이는가?
- 시청자·채널·채팅, 카테고리, 실시간 방송, 최근 18시간 최고가 모두 구조에 포함되는가?
- 오늘 최고·최근 18시간·차트 기간의 범위가 구분되는가?
- 검색에서 스트리머와 카테고리로 이동할 수 있는가?
- 플랫폼·카테고리 선택 이후 실제 방송과 기록까지 연결되는가?
- 다운로드·공지·광고의 위치가 정해져 있는가?
- 모바일에서도 전체 핵심 흐름을 사용할 수 있는가?
