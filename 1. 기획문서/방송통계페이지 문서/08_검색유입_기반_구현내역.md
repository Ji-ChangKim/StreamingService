# 방송 통계 검색 유입 기반 구현 내역

작성일: 2026-10-06
상태: 개발·운영 배포 및 실제 브라우저 검증 완료.

## 결과

통계 메인·플랫폼별·개인 주소를 직접 방문하면 최초 HTML부터 통계 전용 제목·설명·대표 주소와 실제 방송 요약·카테고리·첫 25개 이력이 제공된다. 검색로봇과 사용자에게 같은 HTML을 제공하며 사용자 에이전트로 콘텐츠를 구분하지 않는다.

초기 본문은 숨김 콘텐츠가 아닌 읽을 수 있는 서버 생성 HTML이다. 자바스크립트 실행 후 React가 상호작용 가능한 기존 대시보드로 교체하며 서버에서 전달한 같은 자료를 이어받는다. React 전체 화면의 hydration이나 전체 차트의 서버 렌더링을 구현한 것은 아니다. API 자료가 없으면 예시 수치를 생성하지 않는다.

## 주소와 색인 정책

- /analytics: 전체 방송 통계 대표 주소.
- /analytics/chzzk, /analytics/soop: 플랫폼별 기간 통계와 고유 메타데이터. 실시간 순위의 플랫폼 필터는 기존처럼 별도로 동작한다.
- /analytics/streamer/:channelKey: 공개 채널 고유 키를 사용한 개인 통계. 이름과 플랫폼을 메타데이터에 반영한다.
- 내부 검색·기간·카테고리·정렬 등 쿼리 조합은 noindex,follow를 적용한다. 필터 URL의 대표 주소는 해당 메인·플랫폼·개인 통계 주소다.
- 개인 통계에 현재 기간의 기록이 없으면 noindex로 표시한다. 등록되지 않았고 수집 기록도 없는 임의 채널의 직접 주소는 404를 반환한다. 외부 검색에서 이름을 함께 전달한 채널은 기존 빈 개인 통계 흐름을 유지하며 색인을 제한한다.
- 통계 조회 실패는 503과 no-store로 처리한다. 실패를 정상 빈 통계로 바꾸지 않는다.
- 개발 호스트는 서버 응답에도 noindex를 적용하고 사이트맵을 제공하지 않는다.

사이트맵에는 통계 메인·플랫폼 주소와 실제 저장 기록이 있는 개인 주소를 포함한다. 통계 항목의 lastmod는 실제 관측 시각을 사용한다. 기존 홈·프로필 등의 사이트맵 구성은 유지한다. 검색 도구 계정에 사이트맵을 새로 제출하는 작업은 수행하지 않았다.

## 검증

- 프론트엔드 빌드 및 백엔드 타입 검사 통과. 기존 XLSX 청크와 번들 크기 경고는 남아 있다.
- 페이지 렌더링 3개, 방송 활동 10개, 검색 통합 1개: 총 14개 검사 통과.
- 개발·운영 Chrome에서 자바스크립트를 끄고 통계 제목·실제 요약·방송 링크·대표 주소를 확인했다.
- 일반 브라우저의 최초 활동 집계 API 요청은 0회로 초기 데이터 재사용을 확인했다. 기간 변경은 실제 API로 다시 조회된다.
- 플랫폼 전용 주소, 검색 결과의 실제 href, 개인 통계 진입·새로고침·메타데이터, 320px 가로 넘침과 실행 오류를 확인했다.
- 기록 없는 임의 채널의 404, 운영 사이트맵의 개인·플랫폼 항목, 개발 사이트맵 404와 검색 제외 헤더를 확인했다.
- 검증은 실제 배포 API·DB 응답을 사용했으며 운영 화면에 테스트 데이터를 주입하지 않았다.

## 남은 확인

네이버 서치어드바이저·Google Search Console 계정의 연결·소유 확인 상태, 실제 색인 여부, 검색어별 노출·클릭·게재 순위는 계정 접근으로 확인해야 한다. 검색 기반 구현과 검색 1위 달성은 별개이며 현재 순위를 주장하지 않는다.

카테고리 전용 검색 페이지, 검색 성과 기반의 화면 재배치, 코드 분할과 실제 누적 기록에 대한 성능 개선은 후속 범위다. 현재는 기존 메인·개인 화면과 실제 플랫폼별 기간 통계를 검색 가능한 주소로 연결하는 기반을 완성했다.
