# 방송 활동 대시보드 구현

작성일: 2026-10-05

## 사용자 진입

- 방송 통계 메뉴 → 전체 방송 활동 대시보드.
- 스트리머 검색 → 이름·플랫폼 확인 → 상세 통계.
- 검색 제안에서 채널 선택 → 상세 통계 바로 이동.
- 크리에이터 프로필의 방송 통계 링크 → 대표 채널 상세 통계.
- 공유 주소 직접 접속 → 채널 ID와 기간을 복원.
- 상세에서 검색 결과 또는 전체 통계로 복귀. 브라우저 뒤로가기 지원.

## 화면 변경

- 통계 진입점을 `ActivityDashboard`로 교체했다. 기존 통계 주소는 유지한다.
- 메인은 활동 채널(개), 방송 횟수, 총 방송 시간, 방송 카테고리 수를 먼저 표시한다.
- 시간대별 방송 현황은 방송 활동과 방송 시작 지표를 전환한다.
- 카테고리별 방송 통계는 방송 시간·방송 횟수로 비교하고 선택한 카테고리로 필터링한다.
- 날짜별 방송 활동 추이와 방송 이력을 제공한다.
- 개인 화면은 검색한 스트리머의 방송일 수·방송 횟수·총 방송 시간·평균 기록 시간, 월별 활동 달력과 회차별 기록을 표시한다.
- 최근 7일·30일·90일 및 최대 90일의 직접 날짜 선택을 제공한다.
- 채널 검색은 등록 요청을 보내지 않는다. 조회와 등록을 분리한다.
- 모든 날짜와 시간은 한국 시각을 사용한다.
- 문구는 방송 통계·시간대별 방송 현황·카테고리별 방송 통계·방송 이력으로 통일했다.
- 차트·목록 내부 가로 스크롤을 제공하고 모바일 페이지 전체의 가로 넘침을 수정했다.

## 주소와 API

- 전체: `/analytics?from=YYYY-MM-DD&to=YYYY-MM-DD`.
- 검색: `/analytics?search=검색어&from=YYYY-MM-DD&to=YYYY-MM-DD`.
- 개인: `/analytics/streamer/인코딩된채널키?from=YYYY-MM-DD&to=YYYY-MM-DD`.
- 선택한 채널 이름은 `name`에 보존한다. 실제 조회 대상은 채널 고유 ID로 결정한다.
- API: `GET /api/analytics/activity`.
- 조회 조건: `from`, `to`, `platform`, `channel`, `category`.
- 새 인덱스: `0035_broadcast_activity_channel_index.sql`. 원격 DB에는 아직 적용하지 않았다.

## 지표 기준

- 방송 횟수는 기간에 확인된 플랫폼·채널·방송 ID 조합 수다.
- 시간대별 방송 활동은 수집 회차의 평균 방송 채널 수다. 개인은 해당 채널이 확인된 회차 비율이다.
- 방송 시작은 실제 시작 시각이 제공되고 선택 기간 안에 시작한 방송만 포함한다.
- 방송 시간은 같은 방송이 연속으로 확인된 구간의 합이다. 15분을 넘는 수집 공백은 합산하지 않는다.
- 알 수 없는 방송 시작 시각은 최초 수집 시각으로 대체하지 않는다.
- 방송 중 카테고리 변경을 반영해 기록 구간별로 시간을 배분한다.
- 수집되지 않은 날짜와 시간은 기록 없음으로 표시한다. API 오류는 별도 오류·재시도 화면을 제공한다.
- 요약 응답의 최근 방송 목록은 호환성을 위해 200개로 제한한다. 화면의 방송 이력은 별도 목록 API로 25개씩 추가 조회하며 200개 이후 기록도 제공한다.
- 공통 기록을 한 SQL에서 재사용하고 집계 결과만 반환한다.
