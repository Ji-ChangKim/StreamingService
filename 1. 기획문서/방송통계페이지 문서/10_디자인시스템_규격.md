# VDébut 디자인 시스템 규격 (포털 실제 규격 기준)

작성일: 2026-11-16
기준: 운영 중인 버튜버 도감·캘린더 화면의 코드 규격(`frontend/src/portal/portal.css`, `portalRhythm.css`, `creatorDetail.css`)을 그대로 문서화했다. 방송 통계를 포함한 새 화면은 이 문서를 따른다. 값을 바꾸려면 이 문서와 포털 CSS를 함께 고친다.

---

## 1. 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--vd-blue` | `#2563EB` | 포인트: 링크, 선택 상태, 주요 버튼, 아이브로, 그래프 주 막대 |
| `--vd-ink` | `#19263B` | 본문 제목·숫자 |
| `--vd-muted` | `#6A778B` | 보조 글자 |
| 약한 글자 | `#8593A8` | 메타 정보, 축 라벨 |
| `--vd-line` | `#E4EAF2` | 패널 테두리, 구분선 (상세 화면 `#E2E8F0`) |
| 바탕 | `#F7F9FC` | 페이지 바탕 |
| 면 | `#FFFFFF` | 패널·카드 |
| 약한 면 | `#F8FAFC` / `#F1F5F9` | 입력창, 세그먼트 바탕 |
| 태그 면 / 글자 | `#F1F5FC` / `#6B82A5` | 태그·작은 칩 |
| 강조 면 | `#EEF4FF` (테두리 `#DBE7FB`) | 안내 상자(callout), 1위 강조 |
| 버튼 테두리 / 글자 | `#DCE3EE` / `#40516B` | 일반 버튼 |
| 증가 / 감소 | `#047857` / `#DC2626` | ▲·▼ 수치와 칩 (바탕 `#E8F6EF` / `#FDEEEE`) |

데이터 그래프(통계 화면 확장):
- 주 막대 `#2563EB`, 보조 막대 `#BCD0F7`, 옅은 막대 `#DBE7FB`.
- 두 번째 계열(방송 수·평소)은 먹색 선 `#19263B` 2px. 평소처럼 비교 기준선은 점선.
- 단계 색(시간대 칸): 파랑 한 가지의 명도 단계 `#EEF4FF → #C9DAFB → #8FB1F2 → #4A7FE0 → #1D4FB8`.
- 점유 막대: `#2563EB → #5B8DEF → #8FB1F2 → #BCD0F7 → #DBE7FB`, 기타는 `#F1F5F9`.
- 플랫폼 로고는 브랜드 가이드라인 원본만, 플랫폼 색을 그래프에 쓰지 않는다.

## 2. 글자

- 글꼴: `Inter`, `Noto Sans KR`. 숫자는 `font-variant-numeric: tabular-nums`.
- 제목 공통: 줄 높이 1.35, 자간 -0.035em.

| 단계 | 크기 / 굵기 | 쓰임 |
|---|---|---|
| 페이지 제목 h1 | 32 / 800 (모바일 25) | 목록·통계 첫 화면 제목 |
| 상세 제목 | 26 / 800 | 채널·프로필 이름 |
| 섹션 제목 h2 | 22 / 750 (패널 안 20) | 섹션의 결론 문장 |
| 아이브로 | 11 / 750, 파랑, 자간 0.025em | 섹션 라벨(무엇에 대한 섹션인지) |
| 큰 숫자 | 28~34 / 800 | 요약 카드 수치 |
| 본문 | 14 / 400, 줄 높이 1.65~1.8 | 문단 |
| 작은 글자 | 12 | 메타, 범례, 보조 설명 |
| 최소 | 11 | 칩·축 라벨 (모바일 10까지) |

한국어 줄바꿈: 본문 최상위에 `word-break: keep-all; overflow-wrap: break-word;`, 여러 줄 문단에 `text-wrap: pretty;`.

## 5. 컴포넌트

- **페이지 머리**: 아이브로(선택) + h1 + 설명 한 줄(14, 보조색). 오른쪽에 검색이나 주요 버튼.
- **섹션 머리**: 아이브로(파랑, 섹션 이름) + h2(그 섹션의 결론 문장) + 오른쪽에 세그먼트나 글자 버튼. 결론이 없는 섹션은 h2에 섹션 이름을 쓴다.
- **패널**: 흰 면, 1px 선, 모서리 14, 안쪽 24. 패널 안 제목 20.
- **요약 카드**: 패널과 같은 모양. 라벨 12(보조색) → 큰 숫자 → 보조 문장 12 또는 칩. 첫 카드만 넓게(1.35배), 테두리 `#C9D9F6`.
- **버튼**: 일반(흰 면·`#DCE3EE` 테두리·`#40516B` 글자), 주요(파랑 면·흰 글자), 글자 버튼(파랑 12, 650). 높이 44.
- **세그먼트**: 바탕 `#F1F5F9`, 안쪽 버튼 12/700 `#64748B`, 선택은 흰 면 + 파랑 글자 + 그림자 `0 1px 4px rgba(15,23,42,.08)`.
- **탭**: 글자 14/700, 선택은 파랑 글자 + 아래 2px 파랑 선, 아래 1px 구분선.
- **칩**: `#F1F5FC` 면, `#6B82A5` 글자, 11, 모서리 5. 상태 칩(여유·혼잡·▲▼)은 1장의 증가·감소 색.
- **정보 목록(키-값)**: 왼쪽 라벨 12 보조색, 오른쪽 값 12~13 먹색, 줄마다 1px 구분선.
- **순위 줄**: 순위 숫자(15/800) → 아바타(둥근 사각 40) → 이름 15/700 + `{플랫폼 아이콘} {플랫폼} / {소속}` 12 → 보조 정보 → 수치 막대(6px, 파랑) → 숫자 15/800 → 버튼(작은 버튼).
- **안내 상자(callout)**: 강조 면, 모서리 16, 안쪽 24~30.
- **빈 상태**: 가운데 정렬, 글자 14 보조색, 위아래 48.

## 6. 반응형

- 1000px 이하: 좌우 여백 24, 3단 → 2단.
- 760px 이하: 2단 → 1단, 요약 카드 2열(첫 카드는 한 줄 전체).
- 639px 이하: 좌우 16, 패널 안쪽 16, 버튼 글자 11~12, 아래 고정 메뉴만큼 바닥 여백.
