## 0. 왜 만드는가

> **여러 인터넷 방송 플랫폼의 현재 규모와 시간에 따른 변화를 한곳에서 모니터링하고, 카테고리·스트리머·방송 랭킹을 통해 지금의 스트리밍 트렌드를 이해하도록 만든다.**

사용자는 이 페이지에서 “지금 어디에 시청이 모이는가, 무엇이 인기 있는가, 어떤 방송이 큰 기록을 만들었는가”에 답을 얻고 실제 방송과 개인 기록으로 이동한다.

VDébut는 데뷔 일정으로 새로운 스트리머의 시작을 알리고, 방송 통계로 현재 방송 환경과 활동을 계속 확인할 이유를 제공한다. 시청자는 관심 방송을 찾고, 데뷔 준비생·신입 버튜버·활동 중 스트리머는 방송 환경과 사례를 파악해 준비와 회고에 참고한다.

이번 추가 요구에 따라 기본 통계 범위는 **플랫폼 전체 인터넷 방송**으로 잡는다. 버튜버로 분류한 일부 채널의 집계를 플랫폼 전체 수치로 제시하지 않는다.

| 핵심 질문 | 제품의 답 |
| --- | --- |
| 무엇을 위한 페이지인가? | 인터넷 방송 실시간 모니터링과 트렌드 분석 |
| 왜 필요한가? | 플랫폼별로 흩어진 시청·방송·채팅과 콘텐츠·개인 기록을 같은 흐름에서 비교하기 위해 |
| 무엇이 첫 화면의 주인공인가? | 플랫폼별 시계열, 현재 플랫폼 순위, 카테고리·방송·최고 기록 순위 |
| 어떤 결과를 얻는가? | 현재 현황·추세를 파악하고 관심 콘텐츠·방송·스트리머를 찾아간다 |
| 우리 홈페이지와 어떻게 연결되는가? | VDébut의 기존 헤더·밝은 화면·브랜드 색상을 공유하고 기존 개인 페이지로 이어진다 |

## 1. 사용자와 해결할 문제

| 사용자 | 질문 | 제공할 결과 |
| --- | --- | --- |
| 시청자·팬 | 지금 어떤 콘텐츠·방송이 활발한가? | 플랫폼·카테고리·방송 순위와 실제 방송 연결 |
| 데뷔 준비생·신입 버튜버 | 관심 플랫폼·시간·콘텐츠의 방송 환경은 어떤가? | 현재와 시간별 시청·채널·채팅 현황 및 실제 방송 사례 |
| 활동 중 스트리머 | 관심 방송의 추이와 최고 기록은 어떠한가? | 최근 기록·개인 이력·개별 방송 상세 |
| 방송 동향을 살피는 이용자 | 자료를 같은 기준으로 비교·보관할 수 있는가? | 시각·범위가 명확한 비교와 데이터 다운로드 |

해결하려는 문제는 분산된 플랫폼 탐색, 현재와 과거 지표의 혼동, 합계·순위와 실제 방송의 연결 부족이다. 이용 시간 단축·재방문 증가는 검증할 가설이며 이미 입증된 효과로 표현하지 않는다.

## 4. 대상 플랫폼과 완료 범위

2026-09-17 사용자 요청에 따라 현재 노출 대상은 **SOOP·치지직**이다. 트위치·씨미는 모든 화면 영역과 검색·다운로드에서 임시 숨김 처리한다. 첨부 화면에 수치가 있다는 사실은 VDébut에서 같은 데이터를 수집할 수 있다는 증거가 아니다.

| 플랫폼 | 목표 데이터 | 현재 범위 |
| --- | --- | --- |
| SOOP | 현재·과거 시청·채널·채팅·카테고리·방송·최고 기록 | 지표별 수집·집계 범위 검증 필요 |
| 치지직 | 동일 | 지표별 수집·집계 범위 검증 필요 |
| 트위치 | 향후 재검토 | 사용자 요청으로 임시 숨김 |
| 씨미 | 향후 재검토 | 사용자 요청으로 임시 숨김 |

현재 범위에서 수집이 확인된 플랫폼·지표부터 공개한다. 트위치·씨미는 사용자 요청에 따라 공개 범위에서 제외하고, 향후 재노출 여부를 별도로 결정한다. 부분 공개 시 지원 범위를 명시하고 나머지는 미완료로 관리한다. 플랫폼별 비교 범위(전체/언어권/확인 채널)가 다르면 전체 합산을 강행하지 않는다.

## 5. 첫 화면과 탐색 흐름

- 기본: 전체 플랫폼, 전체 카테고리, 최근 24시간 시청자 추이.
- 상단: 시계열 8열 / 플랫폼 랭킹 4열.
- 중단: 실시간 카테고리 랭킹 전체 폭.
- 하단: 실시간 방송 7열 / 최근 18시간 최고 5열.
- 제목 영역: 통합 검색·다운로드·기준 시각. 필요한 공지 한 줄.
- 기존 VDébut 상단 헤더를 유지한다.
- 플랫폼 → 카테고리 → 방송 → 스트리머 → 개별 기록으로 탐색한다.

차트 기간 변경은 차트에만 적용한다. 플랫폼 랭킹·카테고리·실시간 방송은 현재를, 최고 기록은 최근 18시간을 유지하며 각 영역에 기준을 붙인다. 과거 차트 지점에서 진입한 방송은 “선택 시각 방송”이라는 별도 결과로 구분한다.

## 7. 지표·집계 계약

| 지표 | 정의·범위 |
| --- | --- |
| 현재 동시시청 합계 | 같은 기준 시점의 고유 방송별 동시시청 수 합. 고유 사람 수로 해석하지 않음 |
| 활성 채널 수 | 기준 시각에 방송 중인 고유 채널 수. 반복 수집·다중 행 중복 제거 |
| 채팅량 | 공통 시간 구간의 채팅 메시지 수. 기본 표현은 메시지/분이며 누적값·고유 참여자 수와 구분 |
| 플랫폼 오늘 최고 | 오늘 00:00 KST부터 기준 시각까지 관측한 플랫폼 동시시청 합계의 최대값 |
| 카테고리 점유율 | 현재 선택 플랫폼 범위의 시청 합계를 분모로 한 해당 카테고리 시청 비율 |
| 방송 점유율 | 해당 랭킹에 표시한 플랫폼·카테고리 범위의 시청 합계 대비 해당 방송 비율 |
| 방송별 18시간 최고 | 기준 시각 직전 18시간 안에 관측된 해당 방송 세션의 최대 시청 수 |
| 채널별 18시간 최고 | 같은 18시간 창 안에 해당 채널이 기록한 방송 관측값의 최대. 채널당 한 행 |
| 개인 기간 평균 | 유효 관측 시간으로 가중한 평균. 서로 다른 방송 평균의 단순 평균 금지 |

### 반드시 구분할 것

1. 오늘 최고와 최근 18시간 최고는 별도 시간 창이다.
2. 플랫폼들의 오늘 최고를 더한 값은 전체 플랫폼의 동시 최고가 아니다.
3. 각 방송의 최고값을 더한 값도 플랫폼의 최고값이 아니다.
4. 채팅 데이터 없음은 0건이 아니다. 지원 플랫폼만 비교하고 누락을 표시한다.
5. 기간이 일부만 수집되었다면 최고값도 확보한 구간의 기록임을 표시한다.
6. 최고값이 같으면 최근 최고 발생 시각, 안정적인 방송/채널 식별자 순으로 일관되게 정렬한다.
7. 방송이 게임을 바꿨다면 최고 기록에는 그 시각의 콘텐츠를 연결한다.
8. 채팅 원문·참여자 개인정보를 대시보드 지표 제공에 불필요하게 노출하지 않는다.
9. 새로 발견한 시각을 실제 방송 시작 시각으로 바꾸지 않는다.
10. 범위가 다른 플랫폼을 한국 전체·버튜버 전체라고 임의 묶지 않는다.

## 8. 검색·상세·다운로드

### 검색과 상세

카테고리 결과는 플랫폼과 카테고리 조건을 적용한다. 스트리머 결과·랭킹 이름은 동일 채널의 개인 상세로 연결한다. 과거 기록 클릭은 해당 방송 상세를 펼친다. 방송 시청과 다시보기는 실제 유효 URL만 사용한다.


#### 2026-09-17 스트리머 검색 수용 기준

- 공개 등록 채널 전체(SOOP·치지직)를 이름으로 검색하고 현재 수집 방송·이름이 확인된 최근 18시간 기록을 함께 제공한다. 외부 플랫폼의 모든 채널을 검색하는 기능은 아니다.
- 대소문자·띄어쓰기 정규화, 같은 채널 중복 제거, 플랫폼 구분, 확인된 현재 방송에만 LIVE 표시를 적용한다.
- 검색 버튼·Enter·방향키 선택을 지원하며 검색 중, 결과 없음, 오류와 재시도 상태를 제공한다. 이전 검색 응답이 새 검색 결과를 덮지 않는다.
- 등록 채널은 최대 20개를 반환하고, 추가 결과가 있으면 이름을 더 입력하도록 안내한다.
- 스트리머 상세에서 플랫폼 채널, 등록된 VDébut 프로필, 현재 확인 방송 및 최근 18시간 기록으로 이동한다. 자료가 없으면 방송 종료나 0명으로 대신 표시하지 않는다.
- 실제 제공 범위와 검증 결과는 [개발 반영 결과](./03_DEV_반영결과.md)에 기록한다.

### 전체 데이터 다운로드

“전체”는 **사용자가 선택하고 확인한 플랫폼·기간·종류 안의 전체 결과**다. 화면의 상위 랭킹 몇 행만 내려받는 기능이 아니다.

- ZIP 안에 종류별 CSV와 범위·생성 시각·집계 기준·누락을 설명하는 메타데이터를 포함한다.
- 현재 플랫폼 / 시계열 / 카테고리 / 현재 방송 / 18시간 최고를 별도 파일로 구분한다.
- 현재 자료에는 기준 시각, 시계열에는 선택 기간, 최고 자료에는 18시간 시작·끝을 명시한다.
- 방송·채널 모드와 플랫폼·카테고리 조건을 기록한다.
- 시계열의 화면 축약과 무관하게 제공 가능한 원래 조회 해상도를 명시해 내보낸다.
- 큰 결과는 준비 상태와 완료 파일을 제공하며 일부 행을 조용히 잘라내지 않는다.
- 이름·제목 등 외부 문자열은 CSV 수식으로 실행되지 않게 내보낸다.
- 다운로드는 공개 가능한 집계·방송 메타데이터 범위이며 채팅 원문 다운로드는 포함하지 않는다.

## 10. 성공 검증

### 출시 전

- 지원 범위에서 FR-01~FR-12를 검증하고 S-01~S-07을 실제 데이터로 수행한다.
- 같은 기준의 합계·카테고리·방송 수가 일치한다.
- 오늘 최고와 18시간 최고, 방송/채널 단위의 계산 경계를 검증한다.
- 미지원 플랫폼·채팅·누락 구간이 0 또는 정상 수치로 오인되지 않는다.
- CSV의 전체 결과 수·범위·시각이 조회와 일치한다.
- 모바일·키보드에서 검색·지표 전환·랭킹·상세·다운로드가 가능하다.

### 출시 후

| 지표 | 정의·목적 |
| --- | --- |
| 현황 이해 과제 성공률 | 시청자·스트리머가 현재/최고/기간/범위를 정확히 읽는지 사용자 검증 |
| 랭킹 탐색 도달률 | 랭킹을 본 세션 중 조건 선택 후 실제 방송·개인·기록에 도달한 비율 |
| 지표 활용 | 시청·채널·채팅 전환과 해당 데이터의 실제 표시를 구분해 기록 |
| 다운로드 완료율 | 요청 대비 전체 파일 생성·제공 성공 비율. 클릭만 성공으로 집계하지 않음 |
| 7일 내 재방문율 | 관찰 기간이 확보된 방문 집단의 7일 내 통계 재방문 |
| 데이터 실패·지연율 | 전체 조회 중 실패·지연 비율. 성공 방문만으로 품질을 평가하지 않음 |

현재 실측 기준선은 없다. 정상 운영 초기 2주 데이터를 기준선으로 확보해 개선 목표를 정한다. 외부 방송 클릭을 실제 시청 완료나 시청자 증가로 간주하지 않는다.

## 11. 디자인·사용성 기준

- 기존 VDébut의 로고·상단 메뉴·밝은 회청 배경·흰 카드·남색 제목·파란 강조를 사용한다.
- 레퍼런스에서 가져올 것은 정보의 우선순위와 비교 구조다.
- PC 상단 2열, 전체 폭 카테고리, 하단 두 랭킹을 사용한다.
- 긴 소개나 중복 KPI 카드가 차트와 순위를 화면 아래로 밀지 않게 한다.
- 공식 플랫폼 로고의 색·형태·배경은 임의 변형하지 않는다.
- 공지·광고·계정 기능은 통계 탐색을 가리지 않는 보조 영역에 둔다.
- 세부 규격과 모바일 순서는 IA를 따른다.

## 12. 선행 확인과 단계

1. 플랫폼별 API·수집 범위·관측 간격·기록 보유 기간·채팅 지표 지원을 검증한다.
2. 현재 합계·플랫폼·추이·카테고리·실시간 방송을 연결한다.
3. 최고 기록 집계, 개인 기록, 통합 검색·다운로드·공지·광고 연결을 완성한다.
4. 데이터 정합성·시간 경계·복원·모바일·측정 체계를 확인한다.

수집 가능 여부가 확인되지 않은 기능을 문서에서 사라지게 만들지 않는다. 제공 불가가 확인되면 이유와 대체 제공 범위를 기록하고 제품 범위를 다시 결정한다. 신규 계정·광고 제거 상품, 성공 예측·추천 점수, 채팅 원문 분석은 별도 과제다.
