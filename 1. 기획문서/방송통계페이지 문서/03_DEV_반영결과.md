## 1. 이번 반영의 목적

방송 통계에 들어온 사용자가 현재 시청 규모, 관심을 받는 카테고리와 방송, 최근 최고 기록을 한 화면에서 확인하도록 구성했다. VDébut의 밝은 배경, 흰 카드, 남색 제목과 파란 강조색을 유지했다.

플랫폼 전체를 비교하는 서비스로 확장하기 위한 화면 구조를 구현했으며, 현재 수집 가능한 범위는 화면 상단과 플랫폼 카드, 통계 안내에 명시한다. 수집하지 않은 지표를 0이나 예시 숫자로 대체하지 않는다.

## 2. 반영된 기능

| 영역 | 구현 내용 |
|---|---|
| 상단 | 스트리머·카테고리 통합 검색, 플랫폼 필터, 수집 현황 안내, 새로고침, 데이터 다운로드 |
| 추이 | 시청자·채널 차트, 최근 6/12/24시간 선택, 플랫폼 범례 선택, 실제 수집 지점 확인, 데이터 표 |
| 플랫폼 | 현재 동시시청 합계, 방송 채널 수, 한국 자정 이후 확인된 최고 합계 |
| 카테고리 | 플랫폼별 원본 카테고리, 시청자·채널 정렬, 점유율, 전체 목록 펼치기 |
| 실시간 방송 | 시청자 순위, 프로필, 방송 제목, 카테고리, 제공되는 경우 방송 시작 시각 |
| 최고 기록 | 최근 18시간의 방송별 최고 및 채널별 최고, 목록 펼치기 |
| 방송 상세 | 현재 시청자, 확인된 최고값과 시점별 기록, 플랫폼 방송·채널 외부 링크 |
| 다운로드 | 집계 기준·플랫폼·실시간 방송·카테고리·시계열·방송 최고·채널 최고, 총 7개 엑셀 시트 |
| URL | 플랫폼·카테고리·기간·지표 상태 유지, 뒤로 이동 시 복원 |
| 모바일 | 카드 재배치, 상단 메뉴 두 줄 배치, 320px 이상 화면에서 가로 넘침 방지 |

다운로드는 화면에 보이는 상위 6개/12개에 제한되지 않는다. 선택 범위의 전체 자료를 저장한다. PRD의 CSV 묶음 제안은 이번 개발 환경에서 동일한 자료 구성을 가진 `.xlsx` 7개 시트로 구현했다.

## 3. 현재 데이터 제공 범위

| 구분 | 이번 배포에서 제공하는 범위 |
|---|---|
| 치지직 현재 방송 | 인기 방송 상위 최대 100개. 다음 페이지 커서 처리 및 채널 중복 제거 적용 |
| SOOP 현재 방송 | 등록 순서로 고정한 VDébut 등록 채널 최대 40곳의 방송 여부 조회 |
| 지난 시계열 | 기존 DB에 저장된 치지직 수집 기록 + 현재 조회 시점. 기록 없는 구간은 연결하지 않음 |
| 최근 18시간 최고 | 해당 기간에 저장된 치지직 기록 + 현재 확인된 방송. 채널을 식별하지 못한 기록은 방송 순위에는 포함하고 채널 순위에서는 제외 |
| SOOP 과거 기록 | 기존 저장 자료가 없어 현재 조회 값만 제공 |
| SOOP 카테고리·시작 시각 | 원본 응답에 없는 항목은 미제공으로 표시 |
| 트위치·씨미 | 연결 준비 상태. 합계나 순위에 임의의 숫자를 추가하지 않음 |
| 채팅 | 연결 준비 안내 표시 |
| 광고 | 광고 슬롯 위치만 예약. 실제 광고가 연결되기 전에는 노출하지 않음 |

플랫폼 전체 시청자 수나 고유 이용자 수를 제공하는 것으로 표현하지 않는다. 플랫폼 간 중복 시청자는 제거하지 않은 동시시청 합계다.

## 4. SOOP·치지직 브랜드 적용

- SOOP: 저장소의 `soop_symbol_blue.svg` 원본 사용.
- 치지직: 저장소의 `chzzk Icon_01.png` 공식 원본 사용. 배포 환경의 공백 경로 404 문제를 해결하기 위해 **같은 파일을 가공 없이** `chzzk-icon-01.png`로 복사해 연결했다.
- 치지직 원본·복사본 SHA-256 동일: `5602327E993D10B8B99966194DC87D8C84CC8A7A99769484CE81B6AF977FFDA2`.
- 로고 높이 20px, 가로는 원본 비율 유지, 사방 보호 여백 6px.
- 모바일에서도 로고 크기와 보호 여백을 축소하지 않는다.
- 로고 자체의 색상, 배경, 투명도, 모양, 필터를 변경하지 않는다. 선택 상태는 버튼 테두리와 배경에 적용한다.
- 근거: 저장소의 `frontend/public/BrandGuidelines/PLATFORM_BRAND_GUIDELINES.md`. 6px 여백은 높이 20px의 25% 이상이라는 내부 기준을 충족한다.

## 5. 데이터 처리와 배포 범위

- 새 읽기 전용 API: `GET /api/analytics/broadcast-statistics`.
- 현재 화면은 기존 예시 데이터 대체 API를 호출하지 않는다.
- 플랫폼 요청 실패, 일부 성공, 실제 방송 없음, 연결 준비 상태를 구분한다.
- 현재 방송은 화면이 활성화되어 있을 때 60초 간격으로 확인한다. 플랫폼 요청에 제한 시간을 두고 응답을 최대 60초 캐시한다.
- 누락된 시청자 수는 실제 0명과 구분한다. 일부만 수집된 현재 시점은 차트에서 완전한 과거 시점과 연결하지 않고, 당일 최고 합계 산출에서 제외한다.
- 기존 `snapshot_at` 생성 방식의 시간대 문제를 피하기 위해 과거 기록의 실제 UTC `collection_started_at`을 사용한다.
- 같은 수집 시점의 방송 중복을 제거한 뒤 합산한다. 플랫폼의 최고값은 개별 방송 최고값을 더해 만들지 않는다.
- 새 API는 DB 조회만 수행한다. 테이블·스키마·기존 데이터를 수정하거나 마이그레이션을 실행하지 않았다.
- 운영 사이트 배포와 Git 커밋·푸시는 수행하지 않았다.
