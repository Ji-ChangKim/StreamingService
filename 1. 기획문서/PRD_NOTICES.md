# 📢 [PRD] 공지사항 모듈 제품 요구사항 정의서 (Notices)

- **제품명**: V-DEBUT HUB
- **문서 구분**: 기능별 PRD (1. 공지사항 모듈)
- **작성일**: 2026-07-30
- **문서 상태**: Approved

---

## 1. 개요 및 목적 (Overview & Objective)

공지사항(Notices) 모듈은 V-DEBUT HUB 플랫폼의 **공식 시스템 업데이트, 서비스 점검 안내, 검수 정책 변경, 이벤트 및 크리에이터 가이드 공지**를 유저(시청자, 버튜버, 에이전시)에게 투명하고 정확하게 전달하기 위한 정갈한 인포메이션 센터입니다.

---

## 2. 사용자 역할별 요구사항 (User Needs)

1. **시청자 (Viewer)**:
   - 서비스 점검 시간 및 기능 업데이트 소식을 빠르게 확인.
   - 플랫폼 내 새로운 기능(예: 타임존 변환 기능 개선) 사용법 확인.
2. **크리에이터/에이전시 (Creator/Agency)**:
   - 데뷔 일정 검수 승인 기준 변경 및 소유권 인증 절차 변경 공지 확인.
   - 프로모션 및 이벤트 공지 참여.
3. **운영자 (Admin)**:
   - 주요 공지 상단 고정(Pin), 에디터 기반 공지 작성 및 타겟 알림 송출.

---

## 3. 핵심 기능 명세 (Functional Requirements)

### 📌 3.1 공지사항 카테고리 체계

| 카테고리 뱃지 | 대상 내용 | 예시 |
|---|---|---|
| **[📢 서비스 공지]** | 서비스 주요 안내 및 정책 변경 | "V-DEBUT HUB v1.0 정식 오픈 안내" |
| **[🔧 점검/업데이트]** | 서버 점검 및 기능 패치 | "7/31 서버 데이터베이스 정기 점검 안내 (02:00~04:00)" |
| **[🛡️ 검수 정책]** | 데뷔 일정 제출 및 소유권 검증 규정 | "개인세 버튜버 데뷔 일정 검수 승인 기준 강화 안내" |
| **[🎁 이벤트]** | 크리에이터 프로모션 및 시청자 이벤트 | "8월 신입 버튜버 데뷔 릴레이 응원 이벤트 안내" |

---

### 📌 3.2 화면 UI/UX 명세

1. **공지사항 목록 뷰 (`/notices`)**:
   - **상단 고정 공지 (Pinned Notices)**: 중요한 공지는 상단에 핀 아이콘과 함께 보라색 글로우 카드로 최대 3개 고정.
   - **리스트 구성**: `[카테고리 태그] | 제목 | 작성일 | 조회수 | 첨부파일 여부`
   - **검색 및 필터**: 공지 키워드 검색 및 카테고리 탭 필터링.
2. **공지사항 상세 뷰 (`/notices/:id`)**:
   - 리치 텍스트/마크다운 지원 (이미지, 코드, 관련 링크 버튼 포함).
   - 이전 글 / 다음 글 이동 네비게이션.
   - **`[🔗 공지 공유하기]`** 버튼 (클립보드 복사 및 X/트위터 공유).

## 4. 백엔드 및 데이터 구조 (Data Schema)

```typescript
interface SystemNotice {
  id: string; // 'not_2026_01'
  category: 'ANNOUNCEMENT' | 'MAINTENANCE' | 'POLICY' | 'EVENT';
  title: string;
  content: string; // Markdown / HTML Content
  isPinned: boolean; // 상단 고정 여부
  viewCount: number;
  authorAdminId: string;
  createdAtUtc: string;
  updatedAtUtc: string;
}
```
