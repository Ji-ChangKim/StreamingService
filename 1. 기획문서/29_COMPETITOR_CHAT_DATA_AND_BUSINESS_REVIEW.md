## 1 이번 조사로 바뀌는 판단

**현재 역할**: 경쟁사의 공개 운영 자료와 약관 적용 범위 참고다. SSAPI 문의·도입은 현재 계획에 포함하지 않는다. [문의서](./31_SSAPI_PARTNERSHIP_INQUIRY_DRAFT.md)는 미발송 보존 자료다.

**가능한 사업 경로는 있다. 공식 Open API만을 수집 경로로 놓았던 검토에 데이터 공급 제휴를 추가한다. 다만 다른 서비스의 운영 사실이 우리 서비스의 수집·분석·상업 이용 허가를 대신하지는 않는다.**

| 확인 대상 | 확인한 것 | 아직 확인하지 못한 것 |
| --- | --- | --- |
| 소프트콘 뷰어십 | 자체 수집과 외부 공급자를 병행했다는 운영 공지, SSAPI 제휴 소개, 유료 등급과 광고 모집 | 현재 전체 수집 구현, 플랫폼별 별도 합의·계약 조건, 계약 단가·실제 매출 |
| 위플랩 | 채널 연결·방송용 실시간 위젯, 무료 도구와 별도 광고 상품 안내 | SOOP·치지직 각각의 현재 내부 수집 방식, 계약·예외 허용 범위, 광고 매출·후원 수수료 |
| SSAPI | 중계 서버 수집 설명, 채팅·후원 API 및 제휴용 통계, 목적·BM 심사 정책 | 우리 추천 용도의 승인, 상위 플랫폼 권한의 구체적 근거, 해당 신인 채널 제공 범위, 확정 견적 |
| 공식 개발자 약관 | 해당 API·SDK 이용에 붙는 기본 조건 | 경쟁사에 적용되는 개별 계약, 우리 앱의 심사·예외 승인 결과 |

경쟁사를 위법 서비스로 단정하지 않는다. 반대로 공개 자료에 계약서가 없다는 이유로 승인·계약이 필요 없다고 결론 내리지도 않는다. ‘유료 상품을 판매한다’는 확인과 ‘실제로 얼마를 벌고 있다’는 확인은 구분한다.

## 2 소프트콘은 어떻게 운영하는가

### 2.1 확인된 수집 경로와 현재 데이터 범위

운영사의 **2025-03-11 v2.0.1 공지**는 치지직 채팅을 자체 서버 수집으로 전환하고 SSAPI는 SOOP에 사용한다고 설명한다. 이는 당시 운영 경로의 공개 설명이다. 현재에도 같은 구현인지, 자체 수집이 어떤 프로토콜·승인을 사용하는지까지 공개한 자료는 아니다. SSAPI 홈페이지도 소프트콘 뷰어십을 일부 수집 데이터 제공 제휴 사례로 소개한다. [소프트콘 변경 내역](https://viewership.softc.one/changelog), [SSAPI 제휴 소개](https://ssapi.kr/)

중요한 차이는 **2026-11-10 v2.10.0 공지의 현재 채팅 범위**다. 채팅 통계를 로그인 없이 무료로 공개하면서, 채팅은 채널별 숫자만 집계하고 내용과 참여자 정보는 저장하지 않는다고 안내한다. ‘원문을 저장하지 않는다’가 원문을 어떤 단계에서도 처리하지 않는다는 뜻은 아니지만, 이 공지는 본문을 장기 보관해 취향 추천에 사용해도 된다는 허가 사례가 아니다. [해당 운영 공지](https://viewership.softc.one/changelog)

2026-10-23에는 참여자 관계도 기능 공지도 있었다. 그러나 그 과거 공지만으로 현재 참여자 보관 범위를 확정하지 않는다. 최신 안내와 기능별 처리 차이는 운영사 확인 전 미확정으로 남긴다.

### 2.2 확인된 수익 상품

현재 가격 페이지는 월 GO 3,900원, Plus 34,900원, Pro 59,900원, Enterprise 99,900원으로 표시하며 부가세는 별도다. 광고 제거·조회 범위 확대·고급 분석·CSV 등 정보 이용 편의를 단계별로 판매하는 구조다. 채팅 통계 자체는 위 최신 공지에 따라 무료화됐으므로 ‘채팅 열람을 전부 유료로 판다’고 요약하면 부정확하다. [현재 가격표](https://viewership.softc.one/pricing)

실제 사이트에는 광고 자리 판매 안내도 확인됐다. 따라서 확인 가능한 BM은 **기본 통계 유입 → 유료 분석·조회 편의 + 광고 지면**이다. 이것은 상품 구조의 확인이며 실매출·수익성이나 플랫폼이 허용한 계약 내용까지 입증하지 않는다. [현재 서비스](https://viewership.softc.one/)

### 2.3 우리에게 그대로 가져올 수 없는 것

소프트콘의 데이터 이용 안내는 명시적 허가 없이 데이터를 이용한 새 서비스·사이트·DB 구축 및 직간접 수익 목적의 데이터·파생 결과 제공을 제한한다. 유료 회원 가입이나 CSV 다운로드가 우리 추천 서비스의 재배포 라이선스가 되는 것은 아니다. 데이터를 받고 싶다면 별도 이용 허락의 대상이다. [데이터 이용 안내·가격](https://viewership.softc.one/pricing)

## 3 위플랩은 어떻게 운영하는가

### 3.1 공개 자료로 확인되는 처리 흐름

공식 안내와 FAQ에서 확인되는 흐름은 **이용자가 방송 채널 연결 → 위젯 설정 → OBS 등 브라우저 소스에 URL 추가 → 생방송 중 채팅·후원 이벤트 표시**다. 연결 장애에는 대시보드 재연결 절차를 안내한다. 여러 플랫폼을 연결하는 방송인용 도구다. 이를 근거로 모든 플랫폼이 동일한 OAuth·SDK·중계 업체를 쓴다고 특정하지 않는다. [서비스 소개](https://weflab.com/overlay), [공식 FAQ](https://weflab.com/faq)

개인정보처리방침에 YouTube API 사용은 명시되어 있다. 그 사실과 사이트의 SOOP·치지직 개발자 링크만으로 두 플랫폼의 실제 수집 구현·파트너 계약·광고 허용 조건까지 확정할 수는 없다. [개인정보처리방침](https://weflab.com/privacy)

### 3.2 확인된 수익 상품

공식 서비스는 방송 도구를 무료로 소개한다. 별도로 공개한 **2025년 7월 광고 상품 소개서**에는 사이트 메인·설정 페이지의 배너, 기간 단위 캠페인, 독점 노출, 방송용 브랜드 오버레이 스킨이 나온다. 9쪽은 2주 캠페인 배너, 15쪽은 독점 상품의 가격 문의, 17쪽은 방송 화면의 채팅창·구독·목표 등에 브랜드를 노출하는 스킨을 설명한다. 이는 공개 판매 제안이며 현재 캠페인 계약·단가·판매 실적을 확인한 것은 아니다. [위플랩 공식 광고 소개서](https://weflab.com/guide/weflab_ad_2025_07.pdf)

우리에게 참고할 구조는 **반복 사용되는 무료 도구 → 방송인 접점 확보 → 광고·브랜드 노출 상품**이다. 방송 중 시청자의 후원은 스트리머의 수익일 수 있으므로, 후원 알림·룰렛 기능이 있다는 사실만으로 위플랩이 후원 수수료를 받는다고 계산하지 않는다.

### 3.3 우리 서비스와의 차이

방송인을 위해 그 방의 채팅을 화면에 보여 주는 것과, 여러 방의 채팅을 분석해 불특정 시청자에게 추천하는 것은 용도가 다르다. 위젯용 승인이나 이용자의 채널 연결을 우리 AI 분석·공개 추천·광고 허가로 확대할 수 없다. 위플랩처럼 OBS 기능을 늘리는 방향도 이번 단일 핵심 기능 범위에 추가하지 않는다.

## 4 SSAPI라는 실제 제휴 후보

### 4.1 기술적 제공 방식

SSAPI는 플랫폼별 VM과 중계 서버에서 채팅·후원을 수집·파싱해 Socket·REST 형태로 제공한다고 설명한다. 홈페이지의 채팅 통계 API는 제휴 전용이며 5분 집계·기간별 통계 등을 소개한다. **제3자 공급 서비스이며 네이버·SOOP의 공식 Open API와 동일한 주체가 아니다.** 기술 설명은 중계 방식의 근거이지 플랫폼과의 계약 내용 증거는 아니다. [원리와 구성](https://ssapi.kr/docs/additional-info/api), [제품·제휴 소개](https://ssapi.kr/)

### 4.2 사용 승인은 용도와 BM별로 다르다

공개 이용 정책은 신청한 목적·방식·수익모델 범위로 사용을 제한하고, 변경 시 사전 승인을 요구한다. 스트리머 동의를 전제로 제공하며 일반 이용자의 데이터 이용 기간은 최대 30일이다. 다른 용도로 발급받은 키를 추천 서비스에 돌려 쓰는 안은 제외한다. 묵시적 동의 사례가 있다고 신인 전원의 동의를 임의로 추정하지 않는다. [이용 정책](https://ssapi.kr/docs/additional-info/policy)

서버 보관 기간과 외부 이용자의 허용 기간도 다르다. 현재 보관 문서는 기본 정보의 서버 보관과 공개 REST 이력 제공을 구분한다. 우리 DB·통계·추천 특징·백업의 기간은 받은 계약과 이용 조건을 따라야 하며, 파생 라벨을 만들었다는 이유로 무기한 보관할 수 있다고 가정하지 않는다. [보관 정책](https://ssapi.kr/docs/additional-info/data-retention)

### 4.3 데이터 상품에 따라 핵심 기능의 성립 여부가 달라진다

| 받을 수 있는 상품 | 할 수 있는 것 | 할 수 없는 약속 |
| --- | --- | --- |
| 5분 채팅 수·속도 | 대화가 얼마나 활발한지 표시·흐름 조건 필터 | 이야기 주제·팬덤 친절도·AI 화제 추천 |
| 승인된 최소 본문 표본 | 허용 범위에서 화제 분류와 반복 키워드 | 시청자 개인 성향·전체 시청자 대표성 |
| 공급자가 승인 범위 안에서 만든 화제 특징 | 본문 없이 특징 수신·추천에 활용하는 대안 | 공급자가 실제 이 상품을 제공·판매한다는 확정 |

본문 또는 충분한 화제 특징을 사용할 수 없다면 ‘채팅 기반 취향 발견’의 핵심 효용은 미검증 상태로 남긴다. 숫자 API를 계약한 뒤 AI 설명만 붙여 같은 기능이라고 판매하지 않는다.

플랫폼의 권한·스트리머 참여·채팅 작성자 데이터 처리 근거를 구분한다. 공개 채팅, 원문 미저장, 닉네임 제거, 서버 이전, 광고 페이지 분리 중 어느 하나만으로 나머지 조건이 해결됐다고 결론 내리지 않는다. 이 문서는 계약 적용의 검토 범위를 정리한 것이며 개별 운영사의 계약 적법성을 판정한 문서는 아니다.

## 6 우리에게 가능한 경로와 선택 순서

| 경로 | 실현 가능성 판단 | 개발 전 필요한 결론 |
| --- | --- | --- |
| **참여 스트리머 + 공식 API·별도 허용** | 치지직은 공식 이벤트 경로로 조건부 기술 검증 후보. SOOP은 공개 SDK 제약을 고려한 별도 구성 필요 | 본문 분석·최소 집계·게스트 추천·BM을 포함하는 앱/사업 허용 범위 |
| **참여 스트리머 + 데이터 공급 제휴** | 소프트콘·SSAPI의 공개 사례로 실제 운영 경로 확인. 우리 용도 승인은 미확정 | 본문 또는 유효한 화제 특징, 대상 채널·삭제·AI·상업적 공개 권한과 견적 |
| 소프트콘 유료 회원 데이터 재사용 | 구독만으로 새 서비스 구축 허용 안 됨 | 운영사와 별도 데이터 이용 계약이 있는 경우에만 재검토 |
| 공개 방 직접 전수 수집 | 기술 접근 가능성과 장기 운영 권한은 별개 | 수집·이용 근거 확인 전 기본 사업안으로 채택하지 않음 |

우선 제품 범위를 **동의한 신인들의 현재 방송 화제·채팅 흐름으로 지금 볼 방 1~3개를 고르는 기능 하나**로 유지한다. 자체 채팅 뷰어·후원·OBS 도구나 팬 개인별 채팅 추적은 필요하지 않다.

공식 경로와 공급 제휴의 조건을 같은 요구서로 비교한다. 공급 제휴가 본문 분석·추천 공개까지 허용하고 단가가 맞으면 수집 연결 유지 부담을 줄일 수 있다. 단순 숫자 통계만 허용되면 계약비가 싸더라도 핵심 대안으로 선택하지 않는다. 그 경우 공식 참여형 경로를 검토하고, 어느 경로도 성립하지 않으면 채팅 AI를 핵심으로 확정하지 않는다.

아래는 후속 협의 항목이며 이번에 외부로 보내거나 신청하지 않았다.

| 항목 | 제시할 요구·받아야 할 답 |

## 8 비용과 출시 결정에 반영할 것

28번의 30채널 혼합형 **월 $34.01**, 기존 Workers Paid 이용 시 **순증 $29.01**은 공식 참여형의 기술 예산 가정이다. 승인·실측·견적이 아니며, 데이터 계약 비용을 포함한 전체 사업비로 인용하지 않는다. [기존 가정·산식](./28_CHAT_DISCOVERY_FEASIBILITY.md#8-월-비용-모델--인건비-제외)

| 후보 | 월 현금 지출 구성 | 현재 확정 수준 |
| --- | --- | --- |
| 공식 참여형 | 수집 서버·기존 웹 기본료 순증·DB 초과분·허용된 AI + 별도 이용 계약이 있으면 그 요금 | 기술 가정만 존재. 상용 조건·계약비 미확정 |
| 실시간 본문 공급 제휴 | 데이터 이용료 + 수신·집계 서버 + DB + 허용된 AI·전송료 | 공급 견적·메시지 규격 미확정. 기존 서버비를 자동으로 0원 처리하지 않음 |
| 화제 특징 공급 제휴 | 특징 이용료 + 조회·추천 API·DB·필요 캐시 | 상품 제공 여부부터 미확정. 가능하면 자체 본문 분석 비용을 줄이는 대안 |

따라서 SSAPI 이용료를 무료나 임의 월 정액으로 넣지 않는다. 소프트콘 회원 가격과 위플랩 광고 구매비를 데이터 수집 라이선스비로 대신 계산하지 않는다. 인건비는 모든 후보에서 제외한다.

다음 의사결정 순서는 **요구 범위·권한·견적 확인 → 해당 신인과 시간대의 공급 가능성 → 5채널 기술 검증 → 표본 부족을 포함한 추천 효용 → 30채널 제한 출시 판단**이다. 수익 상품은 승인받은 범위에서만 사업 가정으로 반영한다. 광고 계약을 얻는 영업 부담까지 무료 도구의 자동 수익으로 보지 않는다.

이번 결과는 불가능 확정에서 개발 확정으로 뒤집는 것이 아니다. **자체 수집만 개발하기 전에 실제 제휴 경로를 비교할 근거가 생겼다**는 보완이다. 핵심 기능과 현재 화면은 바꾸지 않고, 외부 문의·API 신청·계약·결제·수집·DB 변경·배포는 실행하지 않았다.
