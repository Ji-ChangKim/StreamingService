**프로젝트명**: V-DEBUT (버튜버 데뷔 일정 캘린더)  
**버전**: v1.0 (MVP Final)

## 1. 목적 (Purpose)
본 문서는 V-DEBUT MVP 제품의 요구사항, 기능적 범주, 사용자 시나리오 및 품질 요구사항을 명확히 정의합니다.

---

## 2. 사용자 유저 스토리 (User Stories)

1. **시청자 (Viewer)**:
   - "나는 이번 달과 다음 달에 데뷔하는 신인 버튜버 목록을 월간 캘린더에서 한눈에 보고 싶다."
   - "나는 내가 사는 지역(KST, JST, PST 등) 시각으로 데뷔 시간이 자동으로 계산되어 보이기를 원한다."
   - "나는 내가 사용하는 구글 캘린더에 데뷔 일정을 1-Click으로 저장하고 싶다."
2. **크리에이터 (Creator)**:
   - "나는 방송국 주소만 입력하면 내 닉네임과 프로필 사진이 자동으로 채워져서 10초 만에 데뷔 일정을 등록하고 싶다."
   - "나는 이미 등록한 데뷔 일정이 변경되었을 때 `수정` 버튼을 눌러 정보를 업데이트하고 싶다."

---

## 3. 기능 요구사항 범위 (Functional Scope)

| 카테고리 | 기능명 | MVP 요구사항 상세 |
| :--- | :--- | :--- |
| **플랫폼 연동** | CHZZK 파서 | 채널 URL, 라이브 URL, 다시보기/클립(`video/14105462`) URL 자동 역추적 연동 |
| | SOOP 파서 | 방송국 메인, 게시글(`memo`) URL 자동 연동 (최신 `chapi.sooplive.co.kr` API) |
| | YouTube 파서 | `@Handle` 및 채널 URL 기반 OpenGraph 메타 스크레이핑으로 프로필/아바타 연동 |
| **캘린더 뷰** | Monthly Grid | 월간 캘린더 그리드, 날짜별 데뷔 인원 표시 및 클릭 시 상세 드로어 출력 |
| | 타임존 전환 | 사용자 시스템 타임존 자동 감지 및 셀렉트 박스 기반 시각 실시간 재계산 |
| | .ics 알림 | iCalendar 규격 (.ics) 다운로드 모듈 제공 |
| **일정 관리** | 신규 등록 | 모달 폼을 통한 데뷔 날짜, 시각, 소속, 설명 입력 및 DB 저장 |
| | 일정 수정 | 기존 등록 건에 대해 `✏️ 수정` 버튼 및 `PUT /api/v1/events/:id` API 연동 |
| | 폼 상태 관리 | 모달 오픈 시 이전 입력값 자동 리셋 및 404 실패 시 수동 작성 자동 전환 |

---

## 4. 비기능 요구사항 (Non-Functional Requirements)

- **성능 (Performance)**: Cloudflare Workers Edge 인프라 기반으로 API 응답 속도 200ms 이내 유지.
- **가용성 (Availability)**: 서버리스 분산 아키텍처로 99.9% 이상 가동률 확보.
- **반응형 웹 (Responsive)**: Mobile, Tablet, Desktop 디바이스 해상도 완벽 대응.
