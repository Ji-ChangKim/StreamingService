- **작성자/담당**: Codex 작성 · 프로젝트 담당자 검토

- **기준**: 원본 브랜드 자산, 기존 메인 기능, 사용자가 첨부한 등록 화면

## 1. 변경 원인과 수정 범위

전체 페이지를 제작하면서 기존 화면을 확장하는 대신 별도 화면 묶음으로 재구성했다. 이 과정에서 원본 가로형 로고를 작은 정사각형 영역에 넣고 브랜드명을 별도 글자로 구성했으며, 기존 무대 이미지와 플랫폼별 하이라이트를 새 메인에 연결하지 않았다. 또한 같은 등록 행동을 헤더·상단 소개·하단에 중복 배치했다. 이러한 브랜드 변경과 기능 누락은 사용자가 요청한 사항이 아니다.

이번 수정은 **브랜딩·기존 기능 복원, 중복 버튼 정리, 첨부 레이아웃 적용**으로 한정한다. 별도 신규 제품 기능이나 DB 변경은 추가하지 않는다.

| 프로필 확인 | 자동 수집한 프로필 카드와 수정 가능한 활동명·소개 표시 | 제출할 정보를 같은 화면에서 확인·수정 |
| 일정 설정 | KST 날짜·시간, 시간 미정·날짜 미정, 선택 공지 링크 | 첨부 이미지의 세 번째 카드에서 일정을 설정 |
| 신청 | 별도 미리보기 단계 없이 같은 폼 하단에서 제출 | 기존 검토 접수와 접수 확인 키 방식은 유지 |
| 조회 오류 | 실패 안내와 수동 활동명·소개 입력 제공 | 조회 실패를 성공이나 임의 프로필로 표시하지 않음 |

하이라이트는 기존 쇼케이스처럼 플랫폼별 오늘·다가오는 **확정 일정**을 보여준다. 엄격한 ‘금주만’ 필터나 새로운 추천 기준을 추가하지 않았다. 금주 데뷔 인원은 별도 집계다. 날짜·시간이 미정인 대상은 기존 달력과 미정 목록에서 확인한다.

## 3. 첨부 이미지의 적용

등록 화면은 다음 순서의 **한 열·세 카드**로 구성한다. 우측 별도 미리보기와 두 단계 이동은 제거했다.

1. **방송 채널 URL 입력**: 주소 필드, 정보 불러오기 버튼, 플랫폼 인식 상태.
2. **불러온 방송국 프로필 정보**: 아바타·플랫폼·활동명·주소, 수정 가능한 활동명과 소개. 소개는 최대 600자.
3. **데뷔 일정 설정**: 날짜·시간·미정 선택, KST 안내, 공지 원문 링크.

하단에는 동의란과 검은색 둥근 등록 신청 버튼을 배치한다. 이미지에 보이는 임의의 일정·인물은 기본 데이터로 넣지 않는다. 자동 처리 시간을 보장하는 문구도 추가하지 않는다.

## 4. 신규 기능의 사전 보고 원칙

이후 신규 기능은 코드를 작성하기 전에 다음 내용을 보고하고 사용자 승인 후 진행한다.

| 보고 항목 | 필수 내용 |
| --- | --- |
| 기능 | 무엇을 추가하며 누구의 어떤 문제를 해결하는지 |
| 동작 | 사용자의 진입 경로·입력·클릭과 시스템 처리 순서 |
| 결과 | 어디에 무엇이 표시·저장·공개되며 다음 행동은 무엇인지 |
| 영향 | 기존 기능·브랜딩·버튼·권한·데이터에 미치는 변경 |
| 실패 상태 | 조회 실패·빈 결과·권한 없음에서의 처리 |
| 검증 | 동작 성공을 어떤 화면·데이터로 확인할지 |

기존 기능 삭제와 브랜드 변경은 개선 작업의 암묵적 범위로 취급하지 않는다. 등록 편의 기능을 상세 소개 입력으로 대체하지 않는다.

## 7. 개인 등록 관리 제거 (2026-10-11)

- 사용자 요청: 내 등록 관리는 필요 없으며, 데뷔 등록 정보가 관리자 페이지에 들어가면 된다.
- 헤더·모바일 메뉴·하단 메뉴의 내 등록 관리 링크와 해당 목록 화면을 제거했다. 하단 메뉴는 세 항목으로 균등 배치한다.
- 관련 소유권 신청·개인 소개 수정 화면과 소개 페이지의 관리 진입도 제거했다. 이전 주소는 찾을 수 없음으로 처리한다.
- 데뷔·소개 신청은 기존 서버 접수 API를 유지한다. 성공 후 완료 안내와 캘린더 복귀만 제공하며 확인 키는 노출·브라우저 저장하지 않는다.
- 기존 문의 답변 조회, 관리자 로그인·검토·공개, 기존 서버 데이터와 권한 API는 보존했다. 신규 알림·외부 발송 기능은 추가하지 않았다.
- 가이드·약관 안내를 운영자 처리 흐름과 일치시켰다.
- 등록 응답 성공 → 관리자 목록에서 신청 정보 확인 → 승인 후 공개를 로컬 통합 테스트로 검증했다. 기존 자동 채널 조회 테스트도 통과했다.
- 개발 배포: `f7439dc8-2c34-4c96-b426-9607556a2ee5` (`streaming-dev`).

## 8. 한·일·미 탐색 범위 (2026-10-11)

- 메인 캘린더의 활동 국가 선택은 전체·한국·일본·미국만 제공한다.
- 표시 시간대는 한국(KST)·일본(JST)·미국 서부(LA)·미국 동부(뉴욕)로 제공한다. 기존 데이터의 시간대 해석과 서버 검증은 유지한다.
- 이전 브라우저 탐색 상태의 제외 국가·시간대는 전체 국가·한국 시간으로 복원한다.
- 프런트엔드 빌드 통과 및 배포 후 실제 선택지 확인. 미국 동부 전환 시 실제 데뷔 일정이 10월 31일 12:00(KST)에서 10월 30일 23:00(뉴욕)로 표시됨을 확인하고 한국 시간으로 복원했다.
- ‘데뷔 하이라이트’ 제목은 카드와 캘린더의 영역 구분 목적으로 추가됐음을 설명했다. 이번 요청은 의도 확인 질문이므로 제목 삭제는 실행하지 않았다.
