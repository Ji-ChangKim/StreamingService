# 42. B1 게임 페이지를 신입 스트리머용 데이터 페이지로

- 작성: 2026-11-24
- 관련: 41번(서비스 시작 계기·애드센스 재검토 계획)의 B1
- 시안: 디자인 캔버스 "B1 게임 페이지" (데스크톱·모바일)

## 1. 목적

| 구분 | 내용 |
|---|---|
| 서비스 계기 | 2번 "신입·하꼬 스트리머가 언제, 어떤 게임으로 방송해야 할지 정보를 얻게 한다" |
| 사용자 질문 | "이 게임, 몇 시에 켜면 덜 묻힐까?", "나 같은 신입은 이 게임에서 어떻게 하고 있지?", "같은 시간에 다른 게임은 어때?" |
| 애드센스 | 다른 곳에서 볼 수 없는 데이터 페이지를 검색에 내보낸다(글이 아니라 데이터의 깊이) |

## 2. 지금과 바뀌는 것

| | 지금 | 바뀐 뒤 |
|---|---|---|
| 기간 | 지금 + 최근 7일 | 최근 30일 중심(지금 숫자는 위쪽에만) |
| 시간 지도 | 요일×시간 평균 시청자 | **방송 1개당 시청자**(기회) / 방송 수 / 전체 시청자 전환 |
| 결론 | 요약 문장 1개 | "덜 붐비는 시간 TOP 3" + 한 줄 결론 |
| 신입 정보 | 없음 | 데뷔 90일 이내 등록 버튜버의 이 게임 방송 수·평균 시청자·켠 시간, 상세로 연결 |
| 다른 게임 | 없음 | 같은 시간대 게임별 방송 1개당 시청자·경쟁 |
| 검색 | 모든 게임 검색 제외 | 데이터가 충분한 게임만 검색 허용 + 사이트맵 |

## 3. 화면 구성

1. **위쪽**: 게임 이름, 한 줄 결론(가장 붐비는 때 vs 방송 1개당 시청자가 가장 많은 때), 지금 경쟁(여유·보통·혼잡)과 순위, 숫자 4개(지금 방송, 지금 시청자, 방송 1개당, 30일 하루 평균 방송)
2. **WHEN 언제 켜면 좋을까**: 덜 붐비는 시간 TOP 3 카드 + 요일×시간 지도
3. **NEWCOMER 신입 버튜버는**: 신입 방송 수(전체 대비 %), 신입 평균 시청자, 신입이 많이 켠 때 + 신입 카드(상세로 연결) + 시간대별 차이 한 줄
4. **TREND 30일 흐름**: 하루 평균 시청자·방송 수
5. **ALTERNATIVE 같은 시간 다른 게임**: TOP 1 시간대의 게임별 비교
6. **TOP 이 게임 상위 채널**
7. **데이터 출처 한 줄** + 집계 기준 링크

## 4. 계산 규칙

| 항목 | 규칙 |
|---|---|
| 기간 | 최근 30일, 한국 시간. 기록을 시간(정각) 칸으로 묶는다 |
| 방송 1개당 시청자 | 그 칸 시청자 합 ÷ 방송 수. 방송 3개 미만 칸은 회색 |
| 덜 붐비는 시간 TOP 3 | 같은 요일 3시간 연속 구간 중 방송 1개당 시청자 평균이 높은 순. 겹치는 구간 제외 |
| 경쟁(지금) | 지금 방송 1개당 시청자를 같은 요일·시간 30일 평균과 비교. 1.2배 이상 여유, 0.8배 이하 혼잡, 그 사이 보통 |
| 신입 | VDébut 등록 버튜버 중 데뷔 90일 이내. 이 게임을 방송한 신입이 3명 미만이면 섹션 숨김 |
| 다른 게임 비교 | 같은 시간대에 방송 3개 이상인 게임만, 최대 5개 |
| 표현 | 평가 표현 금지. "노려 보세요"처럼 선택은 스트리머에게 |

## 5. 검색 허용 기준

- 최근 30일 중 20일 이상 기록이 있고, 하루 평균 방송이 3개 이상인 게임만 검색 허용 + 사이트맵.
- 나머지 게임 페이지는 지금처럼 검색 제외(링크로는 열림).
- 방송 통계 첫 화면, 버튜버 상세의 "주로 한 콘텐츠"에서 게임 페이지로 링크.

## 6. 데이터 한계 (화면에 그대로 밝힘)

- 큰 방송은 **치지직 상위 100개 방송**, 작은 방송은 **VDébut 등록 버튜버**만 기록한다. 등록되지 않은 작은 방송은 빠진다.
- SOOP은 준비 중이라 치지직 기준으로 시작한다.

## 7. 개발 범위 (시안 확정 뒤)

| # | 작업 | 비고 |
|---|---|---|
| 1 | 게임 통계 API 확장: 30일 요일×시간 방송 수·시청자 합, 30일 일별 추이 | 새 수집 없음. 기존 기록 조회 |
| 2 | 덜 붐비는 시간 TOP 3, 경쟁(평균 대비) 계산 | 서버 계산, 10분 캐시 |
| 3 | 신입 버튜버 게임별 기록 | 일일 요약 표(0066) + 등록 버튜버 데뷔일 |
| 4 | 같은 시간 다른 게임 비교 | 같은 기록에서 계산 |
| 5 | 화면 개편(데스크톱·모바일) + 첫 HTML 문장 | 결론 문장이 게임마다 다르게 나오도록 |
| 6 | 검색 허용 기준 + 사이트맵 + 내부 링크 | 5번 기준 |
| 7 | D1 읽기량 확인 | 30일 조회는 하루 1번 계산해 저장하는 방식 검토 |
