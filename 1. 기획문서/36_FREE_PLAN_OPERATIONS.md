# 36. 무료 플랜 운영 기준과 유료 전환 시점

- 결정일: 2026-11-17
- 결정: Cloudflare Workers·D1은 **무료 플랜을 유지**한다. 서비스가 더 자리 잡으면(아래 신호) 유료(Workers Paid, 월 $5)로 바꾼다.

## 1. 무료 플랜 한도 (계정 전체 공유)

| 항목 | 무료 한도 | 넘으면 |
|---|---|---|
| D1 읽기 | 하루 500만 행 | 그날 UTC 0시(한국 오전 9시)까지 조회 실패 |
| D1 쓰기 | 하루 10만 행 | 그날 UTC 0시까지 저장 실패(수집 중단) |
| D1 크기 | 데이터베이스당 500MB | 새 기록 저장 실패 |
| Workers 요청 | 하루 10만 회 | 요청 실패 |
| Workers CPU | 요청당 10ms | 그 요청 오류 |

## 2. 무료 플랜을 버티기 위해 넣은 장치 (2026-11-17)

- 통계 자료는 10분에 한 번만 계산하고, 슬롯이 바뀌면 직전 결과를 먼저 보여 준 뒤 뒤에서 한 번만 다시 계산한다(`backend/src/services/edgeCache.ts`).
- 계산이나 조회가 실패하면 직전 결과·하루 보관한 페이지 사본을 보여 준다. 오류 화면이 심사 로봇에 노출되지 않게 하기 위해서다.
- 홈·소개 목록·소개 상세·방송 통계 첫 화면은 엣지에 저장한다(홈·상세 5분, 목록 1분, 통계 2분).
- 방송 통계 기록 정리는 한 시간에 최대 12회차만 지운다(수집 속도와 같음). 밀린 기록을 몰아 지워 쓰기 한도를 넘지 않게 한다.
- 처리 끝난 문의·신청의 연락 정보 정리(1년)는 행 수가 적어 한도에 영향이 거의 없다.

## 3. 유료로 바꾸는 신호 (하나라도 해당되면)

| 신호 | 확인 위치 |
|---|---|
| D1 하루 읽기가 350만 행(70%)을 넘는 날이 생김 | D1 → vdebut-db → Metrics |
| D1 하루 쓰기가 7만 행(70%)을 넘는 날이 생김 | 같은 곳 |
| D1 크기가 350MB(70%)를 넘음 | D1 → vdebut-db 개요 |
| Workers 오류에 CPU 한도 초과(1102)나 D1 한도 오류가 보임 | Workers → streaming → Metrics → Errors |
| AdSense 승인으로 광고 수익이 월 $5를 넘음 | AdSense 보고서 |

## 4. 점검 주기

- 매월 1회 위 신호를 확인한다. 신호가 없으면 무료 유지.
- 신호가 하나라도 있으면 유료로 바꾸거나, 무료로 버틸 축소안(오래된 기록을 1시간 요약으로 바꾸기, 보관 기간 90일→30일, 치지직 수집 상위 100→50) 중 필요한 것을 고른다.
