# 39. 버튜버 DB 구성안과 상세 페이지 통일 검토

- 작성일: 2026-11-17
- 배경: "버튜버 탐색"은 카드 나열에 가깝다. 서비스의 세 기둥(데뷔 캘린더 = 언제, 버튜버 DB = 누구, 방송 통계 = 어떻게)에 맞춰 "버튜버 DB"로 바꾼다.

## 1. 이름과 주소

- 메뉴 이름: **버튜버 DB** (프로필 상단의 "버튜버 도감" 표시는 "버튜버 DB"로 맞춘다)
- 주소는 그대로 `/creators`(목록)·`/creator/{이름}`(상세). 이미 색인된 주소를 바꾸면 검색 신호가 흩어지므로 바꾸지 않는다.

## 2. DB 목록 화면 구성

| 영역 | 내용 |
|---|---|
| 머리 | 제목 "버튜버 DB" + 한 줄 설명 + 요약 숫자(등록 버튜버 n명 · 이번 달 데뷔 n명 · 지금 방송 중 n명) |
| 검색 | 이름·소속·주요 콘텐츠로 찾기 |
| 빠른 분류 | 이번 달 데뷔 · 지금 방송 중 · 성장 빠른 · 노래 · 게임 · 소속 있음 |
| 필터 | 플랫폼, 데뷔 시기(월), 방송 언어, 주요 콘텐츠, 활동 상태(최근 30일 방송함), 국가, 기록 있는 버튜버만 |
| 정렬 | 최근 데뷔순(기본) · 평균 시청자순 · 성장률순 · 방송 많은 순 · 이름순 |
| 보기 전환 | 카드(사진 중심) / 표(데이터 중심) |
| 표 칸 | 이름 · 플랫폼 / 소속 · 데뷔일 · 주요 콘텐츠 · 최근 30일 방송 · 평균 시청자 · 성장률(첫 주 대비) · 주 방송 시간 |
| 빈 값 | "기록 없음"을 흐리게 표시(0과 구분). 숫자 칸이 비면 정렬에서 뒤로 |
| 랭킹 띠 | 이달의 성장 버튜버 · 신입 시청자 TOP · 꾸준히 방송한 신입(데뷔 30일 안에 방송 8회 이상) |

## 3. 분류 페이지 (검색 입구)

| 주소(안) | 예 | 내용 |
|---|---|---|
| `/creators/debut/2026-10` | 2026년 10월 데뷔 버튜버 | 그달 데뷔 수·플랫폼 비중 요약 문장 + 목록 |
| `/creators/content/노래` | 노래 버튜버 | 그 콘텐츠 버튜버 수, 평균 시청자 상위 + 목록 |
| `/creators/agency/{소속}` | ○○ 소속 버튜버 | 소속 버튜버 목록, 데뷔 순서 |
| `/creators/platform/chzzk` | 치지직 버튜버 | 플랫폼별 목록 |

- 버튜버가 5명 이상인 분류만 검색에 노출(그 아래는 noindex, follow)
- 첫 HTML에 요약 문장과 목록을 넣는다

## 4. 상세 페이지 통일 검토

현재 상세 페이지가 두 개다.

| | 버튜버 DB 상세 `/creator/{이름}` | 통계 채널 페이지 `/analytics/streamer/{채널}` |
|---|---|---|
| 대상 | VDébut에 등록된 버튜버(약 380명) | 수집된 모든 채널(버튜버가 아닌 치지직 상위 스트리머 포함) |
| 내용 | 소개·데뷔 정보·영상·링크 | 방송 기록·시청자·콘텐츠·태그 |
| 검색 노출 | 허용 | 제외 |
| 열리는 곳 | DB 목록, 캘린더 | 방송 통계 검색·순위 |

### 선택지

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 그대로 둠 + 서로 링크 | 두 페이지 유지, 서로 바로가기만 | 작업 적음 | 같은 버튜버가 두 주소로 나뉨. 검색 점수·체류가 흩어짐. 사용자가 헷갈림 |
| B. 완전히 하나로 | 모든 채널을 DB 상세로 | 주소 하나 | "버튜버 DB"에 버튜버가 아닌 스트리머가 섞임. 소개 없는 얇은 페이지가 대량으로 생김(심사에 불리) |
| **C. 버튜버는 하나로, 나머지는 통계 페이지 (추천)** | 등록 버튜버는 `/creator/{이름}` 하나에 **"소개 / 방송 기록" 탭**. 방송 통계 검색·순위에서 등록 버튜버를 누르면 이 페이지의 방송 기록 탭으로 간다. `/analytics/streamer/{채널}`은 등록되지 않은 채널에만 쓰고, 등록 버튜버의 이 주소는 DB 상세로 이동(301) | 버튜버마다 주소 하나로 검색 점수와 내용이 모임. 프로필이 데이터로 풍부해져 심사에 유리. 화면은 기존 채널 통계를 탭 안에서 재사용 | 연결 작업 필요(채널 키 ↔ 프로필 표 `portal_profile_channels`가 이미 있음) |

### 추천: C

- 버튜버 한 명 = 주소 하나 = "누구(소개)"와 "어떻게(방송 기록)"가 한 곳에
- 방송 기록 탭은 누를 때만 불러와 읽기 비용을 늘리지 않음
- 프로필 보강 시안의 ②~⑤(방송 기록 요약·성장 곡선·방송 시간표·콘텐츠별 반응)가 "소개" 탭 요약이 되고, 자세한 내용은 "방송 기록" 탭

## 5. 필요한 데이터 작업 (38번 문서와 연결)

- 등록 버튜버 직접 기록(치지직 신입 공백 해결)
- 채널별 하루 요약 표(목록의 숫자 칸·정렬·랭킹을 가볍게 계산)
- 팔로워 수 하루 1회 저장(성장률 보조 지표)
