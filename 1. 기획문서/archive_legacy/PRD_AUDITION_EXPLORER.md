# 🎙️ [PRD] 오디션 탐색 모듈 제품 요구사항 정의서 (Audition Explorer)

- **제품명**: V-DEBUT HUB
- **문서 구분**: 기능별 PRD (4. 오디션 탐색 모듈)
- **작성일**: 2026-07-30
- **문서 상태**: Approved

---

## 1. 개요 및 목적 (Overview & Objective)

오디션 탐색(Audition Explorer) 모듈은 **예비 버튜버 및 스트리머 지망생들이 국내외 MCN, 에이전시, 프로젝트 팀의 신인 버튜버 모집/오디션 정보를 한눈에 발굴하고, 검증된 에이전시에 즉시 지원하도록 연결**하는 버버튜버 생태계 통합 오디션 인벤토리입니다.

---

## 2. 해결하려는 핵심 문제 (Problem & Solution)

1. **지망생 문제**: 오디션 공지가 트위터, 커뮤니티, 개별 웹사이트에 파편화되어 있어 접수 마감일을 놓치거나 신뢰할 수 없는 오디션을 구분하기 어려움.
2. **에이전시 문제**: 인재 채용 시 타겟 버튜버 지망생 집단에 오디션을 집중 홍보할 수 있는 전용 채널 부재.
3. **솔루션**: V-DEBUT HUB 내에 **검증 배지 기반 오디션 전용 탐색 탭(`/auditions`)**을 신설하여 마감 D-Day, 지원 조건, 아바타 제공 여부를 한눈에 제공.

---

- **지원의 혜택 뱃지**: 
  - `✨ 3D/Live2D 아바타 전액 지원`

  - `🎵 음원 제작 & 굿즈 제작 지원`
- **활동 언어 및 국가**: `🇰🇷 KO`, `🇯🇵 JA`, `🇺🇸 EN`

## 4. 데이터 스키마 명세 (Data Schema)

```typescript
interface VtuberAudition {
  id: string; // 'aud_2026_01'
  agencyId: string;
  agencyName: string;
  agencyLogoUrl: string;
  isVerifiedAgency: boolean; // 검증된 에이전시 여부
  title: string; // 'V-PRO 3기 신인 오디션'
  description: string;
  perks: string[]; // ['Live2D 지원', '장비 지원', '음원 발매']
  targetGender?: 'FEMALE' | 'MALE' | 'ANY';
  languages: string[]; // ['ko', 'ja']
  applyUrl: string; // 외부 Google Form / 채용 페이지 URL
  startAtUtc: string;
  endAtUtc?: string; // null이면 상시 모집
  isAlwaysOpen: boolean;
  status: 'RECRUITING' | 'CLOSED';
}
```
