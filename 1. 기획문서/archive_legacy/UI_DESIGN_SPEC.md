## 2. 5대 핵심 화면 명세

### 2.1 메인 캘린더 탐색 화면 (`/calendar`)
- **상단 내비게이션**: 로컬 시간대 변환 드롭다운 셀렉터 (Asia/Seoul, US West, US East, JST, UTC).
- **필터 바**: 플랫폼 셀렉션 버튼 (ALL, YOUTUBE, TWITCH, CHZZK, SOOP) 및 검색어 즉시 필터링.
- **이벤트 카드**:
  - 아바타, 활동명, 소속, 언어 태그 표시.
  - 검증 배지: `Owner Verified` (보라색), `Official Source` (청록색), `LIVE` (붉은색 점멸).
  - 시간 표시: 사용자가 선택한 로컬 시간으로 자동 계산되어 표기 (`2026.07.29 20:00 KST`).
  - `.ics` 캘린더 다운로드 버튼 및 방송 플랫폼 직접 이동 CTA.

### 2.2 데뷔 일정 제출 폼 모달 (`Studio Submit Modal`)
- **6단계 가이드 폼**:
  1. 크리에이터 활동명 입력
  2. 데뷔 방송 제목 입력
  3. 방송 플랫폼 선택 (CHZZK, YouTube, Twitch, SOOP)
  4. 원본 IANA 시간대 및 날짜/시간 선택
  5. 방송 시청 URL 입력
  6. 소개글 및 검수 요청 제출

### 2.3 운영자 검수 큐 (`Admin Review Queue`)
- 제출된 신규 데뷔 이벤트를 미검수 상태에서 위험도 및 임박도별 정렬.
- 제출 증거 URL, 채널 소유권 확인 후 **'승인 (Publish)'** 또는 **'보완 요청'**, **'거절'** 즉시 처리.
