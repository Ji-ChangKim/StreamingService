# 제품 요구사항 정의서 (PRD v0.2)

- **서비스명**: 치지직 후원 룰렛 템플릿 서비스 (가칭)
- **작성 버전**: v0.2 (Draft)
- **작성일**: 2026-06-13
- **문서 상태**: Draft (초안 작성 중)

---

## 1. 서비스 개요
본 서비스는 치지직(Chzzk) 스트리머가 복잡한 수동 세팅 없이 치지직 계정을 연동한 후, 자신의 방송 아이덴티티에 어울리는 **룰렛 UI 템플릿**을 선택하고 **룰렛 콘텐츠 내용(금액, 가중치 등)**을 디자인하여 시청자 후원 시 OBS 방송 화면 상에 실시간으로 룰렛을 자동 구동해 주는 완전 자동화 웹 서비스입니다. 
추가로, 시청자들에게 확률과 추첨의 투명성을 제공하기 위하여 **시청자 전용 읽기 모드 페이지(룰렛 확률 및 당첨 내역 보드)**를 독립적으로 제공합니다.

---

## 2. 해결하고자 하는 문제 및 핵심 가치

### 2.1. 스트리머 측면의 문제와 해결 (Core Values for Streamers)
1. **쉬운 후원 연동**: 복잡한 소켓 세션 설정 없이 네이버 로그인 및 치지직 OAuth 연동만으로 실시간 후원 수신을 원클릭 구성합니다.
2. **다양한 후원 콘텐츠 확장**: 룰렛 후원 서비스를 시작으로 향후 후원 알림, 후원 자막, 목표치 등 스트리머가 방송 테마에 맞게 유연하게 확장할 수 있는 기초 구조를 다집니다.
3. **나만의 방송 아이덴티티 구축 (다양한 UI 템플릿)**: 단순히 똑같은 룰렛 판을 돌리는 것이 아니라, 룰렛의 디자인 레이아웃, 배경, 폰트, 효과음, 애니메이션, 결과 연출 방식을 다양하게 설계된 **UI 템플릿 프리셋** 중에서 손쉽게 선택하고 커스텀할 수 있게 지원합니다.

### 2.2. 시청자 측면의 문제와 해결 (Core Values for Viewers)
1. **금액 맞춤형 자동 노출**: 시청자가 정해진 치즈 금액 이상을 후원하면, 수동 조작 대기 없이 1.5초 이내에 방송 오버레이에 결과가 시각적 애니메이션으로 즉각 표출되어 참여 재미를 극대화합니다.
2. **신뢰성과 투명성 (읽기 전용 페이지)**: 스트리머가 룰렛 조작이나 거짓 확률을 사용하지 않는지 의구심을 갖는 시청자들을 위해, **시청자 전용 룰렛 보드 페이지**를 제공합니다. 시청자는 로그인 없이 해당 페이지에 접속해 각 룰렛의 당첨 확률과 역대 당첨 이력 로그를 실시간 "읽기 모드"로 조회할 수 있습니다.

## 3. 핵심 사용자 흐름 (Core User Journey)

### 3.1. 스트리머 여정
```text
치지직 OAuth 로그인 (채널 정보 자동 연동)
→ 후원 서비스 선택 (MVP: 룰렛 후원 단독 제공)
→ 룰렛 UI 템플릿 선택 (Basic, Neon, Cute, Premium, Dark 중 택1)
→ 디자인 커스텀 설정 (메인 컬러, 폰트, 효과음, 재생 시간 등 프리셋 기반 지정)
→ 룰렛 세부 내용 제작 (룰렛명, 최소 금액, 아이템 목록, 아이템별 가중치 기입)
→ 방송 연동 적용 (OBS 오버레이 URL 복사 및 OBS 소스 추가)
→ 실행 또는 대기 상태 진입 (연동 에러 발생 시 원인 및 문제 해결 가이드 제공)
```

### 3.2. 시청자 여정
```text
[방송 참여 중] 스트리머 방송 중 지정된 치즈 금액 후원 -> 방송 화면(OBS 오버레이)에서 룰렛 애니메이션 및 당첨 축포 감상
[검증 및 확인] 스트리머가 제공한 공유 링크를 통해 룰렛 정보 페이지 접속 -> 룰렛별 항목 구성, 수학적 확률(가중치 환산 값), 당첨자 및 당첨 결과 로그 투명하게 확인
```

## 4. MVP 기능 요구사항 (Functional Requirements)

### 4.1. 치지직 ID 연동 및 온보딩
- 사용자는 "치지직으로 시작하기" 버튼을 눌러 네이버 OAuth 인증을 진행한다.
- 인증 성공 시 사용자의 `channelId`, `channelName`, `profileImageUrl`, Access/Refresh Token을 자동 연동 및 저장한다.
- 토큰 만료 또는 권한 만료 시 대시보드 상에 `재연동 필요` 인디케이터와 연동 가이드를 노출한다.

### 4.2. 후원 서비스 선택 화면
- 스트리머는 가입 완료 후 제공할 후원 서비스 유형을 선택한다.
- MVP에서는 **룰렛 후원**만 활성화 상태로 제공하며, 후원 알림/목표치/자막 등 확장 피처는 '준비 중(비활성)' 형태로 표시하여 향후 확장 구조를 명확히 제시한다.

### 4.3. 룰렛 UI 템플릿 및 커스텀 디자인 설정
- **기본 UI 템플릿 5종 제공**:
  1. **Basic Minimal**: 깔끔하고 담백한 기본 플랫 룰렛
  2. **Neon Game**: 게임 스트리머에 적합한 화려한 네온 스타일
  3. **Cute Pop**: 파스텔톤의 아기자기한 애니메이션 테마
  4. **Premium Gold**: 고액 후원 리액션에 걸맞은 골드 럭셔리 스타일
  5. **Dark Mission**: 벌칙 또는 도네 미션에 특화된 어둡고 묵직한 레이아웃
- **프리셋 기반 커스텀 기능**: 에디터 복잡도를 줄이기 위해 이미지/사운드 직접 업로드를 배제하고, 제공된 프리셋 범위 내에서 메인 색상, 폰트, 효과음(ON/OFF), 회전 속도, 연출 표시 시간(3~10초)을 제어하도록 구성한다.

### 4.4. 룰렛 내용 제작
- 스트리머는 룰렛별 이름, 트리거가 되는 최소 후원 금액, 룰렛 내 아이템(최소 2개 이상) 및 개별 가중치를 지정한다.
- **후원 메시지 조건 매칭**: 특정 룰렛은 금액뿐만 아니라 시청자의 후원 메시지 내에 특정 텍스트(예: `!룰렛`)가 포함되었을 때만 트리거되도록 옵션 필터를 제공한다.
- **사행성 고지 경고**: 룰렛 생성 화면 하단에 사행성 콘텐츠 운영 책임에 관한 면책 고지 문구를 필수 노출한다.

### 4.5. 적용 및 실시간 상태 관리
- 룰렛 저장 완료 시 고유 오버레이 URL을 발급하고 상태 카드를 통해 동작 상태를 직관적으로 전달한다:
  - `Running (실행 중)`: 정상 수신 대기 상태.
  - `Waiting (대기 중)`: 설정은 완료되었으나 OBS 오버레이가 아직 연동되지 않았거나 룰렛 항목이 불충분할 때 발생.
  - `Error / Revoked (미실행/재연동 필요)`: 토큰 유실 혹은 플랫폼 연동 에러 상태이며, 에러 원인 분석과 문제 해결(Quick fix) 버튼을 연계 노출한다.

### 4.6. 시청자용 투명 룰렛 정보 조회 페이지 (읽기 모드)
- 로그인 없이 접근할 수 있는 오픈 주소(예: `/streamer/{channelId}/roulette`)를 지원한다.
- 해당 페이지 진입 시:
  - 현재 스트리머가 활성화해 둔 룰렛 목록과 최소 발동 금액 표시.
  - 각 룰렛별 당첨 항목과 가중치로 자동 환산된 **정확한 당첨 확률(%)** 노출.
  - 최근 실행된 룰렛 당첨 내역(일시, 후원자명, 획득한 결과 항목)의 실시간 히스토리 로그 출력.

## 5. 정책 정의 (Policy Rules)

| 정책 ID | 정책 항목 | 상세 정책 가이드라인 |
| :--- | :--- | :--- |
| **POL-01** | **템플릿-내용 격리** | - UI 템플릿 디자인을 변경하거나 커스텀 디자인을 새로 적용하더라도, 기존 룰렛 내용(항목명, 최소 금액, 가중치)은 손상 없이 그대로 보존되어야 한다. |
| **POL-02** | **실시간 연속 후원 (큐)** | - 연속적인 후원이 들어올 시 오버레이 화면은 **FIFO 큐**를 통해 이전 룰렛 회전 연출이 정지하고 최종 결과가 다 보인 후, 다음 룰렛 연출로 순차 전이되어야 한다. |
| **POL-03** | **비로그인 읽기 모드 격리** | - 시청자용 읽기 모드 페이지에서는 어떠한 쓰기(Write) 작업이나 관리자 API 권한도 주어지지 않으며, D1 Read 쿼리만을 수행해 스트리머 채널 데이터의 보안을 유지한다. |
| **POL-04** | **결과 신뢰성** | - 룰렛 결과의 난수 산출은 클라이언트(오버레이)가 아닌 안전한 백엔드(Workers/Durable Objects)에서 수행된 후 저장/송출되어 조작 가능성을 완전히 차단한다. |

## 6. 성공 지표 (KPIs)
1. **설정 만족도**: 스트리머 온보딩 시작부터 OBS 오버레이 등록 완료까지의 평균 소요 시간 3분 이하 달성.
2. **실시간 반응속도**: 시청자 후원 유입 후 화면 룰렛 구동 개시까지 지연 시간 평균 1.5초 이내.
3. **투명성 조회 신뢰도**: 시청자용 읽기 전용 확률 페이지 로딩 속도 1초 이내 및 실시간 로그 동기화 일치도 100%.
