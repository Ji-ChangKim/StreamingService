# 37. 사이트 페이지 점검 — 페이지별 목적·목표와 AdSense 심사 통과 조건

- 점검일: 2026-11-17 (배포 ad395c4 기준, Googlebot으로 실제 사이트 측정)
- 배경: AdSense "가치가 별로 없는 콘텐츠"(Low value content) 판정 후 재심사 준비
- 측정 항목: 응답 코드, 검색 허용(robots 메타·X-Robots-Tag), 첫 HTML 본문 글자 수(검색 로봇이 자바스크립트 없이 읽는 양), 사이트맵 포함

## 1. AdSense 심사 통과 조건

Google은 정확한 기준을 공개하지 않는다. 아래는 AdSense 프로그램 정책과 "가치가 별로 없는 콘텐츠" 안내에서 공개된 항목을 우리 사이트에 맞춘 것이다.

| # | 조건 | 우리 상태 | 판정 |
|---|---|---|---|
| 1 | **직접 만든 가치 있는 콘텐츠**가 충분할 것 (다른 곳 복사·자동 생성만으로 채운 페이지가 대부분이면 탈락) | 홈·통계·안내 페이지는 충분. **프로필 296개 대부분이 200~500자, 소개글 상당수가 방송국 소개 복사** | ⚠️ 가장 큰 위험 |
| 2 | **얇은 페이지·중복 페이지**가 사이트의 대부분이 아닐 것 | 언어판 복제 592개 정리 완료(사이트맵 918→326). 얇은 프로필은 일부만 noindex | ⚠️ |
| 3 | **검색 로봇이 본문을 읽을 수 있을 것** (자바스크립트 실행 전 HTML에 내용) | 홈·통계·안내·프로필 모두 첫 HTML 제공 | ✅ |
| 4 | **탐색이 쉬울 것** (메뉴, 페이지 간 링크, 깨진 링크·빈 페이지 없음) | 상단 메뉴 3개, 첫 HTML에도 안내 링크. 게임·태그 페이지 첫 HTML은 빈 껍데기 | ⚠️ |
| 5 | **"공사 중" 같은 미완성 페이지가 없을 것** | SOOP 통계: 데이터 준비 중 안내만 있는데 검색 허용 | ⚠️ |
| 6 | **개인정보처리방침에 쿠키·광고 고지** | 제3자 광고 쿠키, 거부 방법, 해외 이전까지 포함 | ✅ |
| 7 | **운영 주체·연락 수단** (소개·문의) | 소개·문의·운영 주체 명시 | ✅ |
| 8 | **ads.txt·사이트 소유 확인** | ads.txt와 소유 확인 태그 있음 | ✅ |
| 9 | **저작권·정책 위반 콘텐츠 없음** | 버튜버 프로필 이미지는 각 플랫폼 원본 링크 사용, 출처 표기. 삭제 요청 창구 있음 | ✅ (요청 시 즉시 대응) |
| 10 | **오류 없이 안정적으로 열릴 것** | DB 한도 대비 사본·직전 결과 제공 장치 배포 | ✅ |

**결론:** 기술·정책 조건(3, 6~10)은 갖췄다. 남은 위험은 **콘텐츠 가치(1·2)**, 특히 사이트맵의 90%를 차지하는 프로필 페이지다.

## 3. 재심사 전 할 일 (우선순위)

| 순위 | 할 일 | 이유 | 규모 |
|---|---|---|---|
| 1 | **프로필 보강**: 데뷔 정보 문장, 방송 통계 요약(기록 있는 채널), 같은 주 데뷔 버튜버 링크를 첫 HTML과 화면에 | 사이트맵의 90%가 프로필. 조건 1·2의 핵심 | 시안 반나절 + 개발 1일 |
| 2 | **보강 후에도 얇은 프로필은 검색 제외**(페이지는 유지) | 남은 얇은 페이지 비중 축소 | 반나절 |
| 3 | 등록 페이지 2개에 등록 안내 본문 추가(또는 검색 제외) | 190자 페이지가 검색 대상 | 반나절 |
| 4 | SOOP 통계는 데이터 준비 전까지 검색 제외·사이트맵 제외 | 미완성 페이지 | 1시간 |
| 5 | 집계 기준 사이트맵 추가, 게임·태그 페이지 제목·메타 수정 | 신호 정리 | 1시간 |
| 6 | 가이드 글 3편 + 주간 데뷔 정리 3편 | 직접 만든 콘텐츠 강화 | 1.5일 |
| 7 | Search Console 사이트맵 재제출 → 재심사 요청 | — | — |
