# 40. 버튜버 DB 나열·정렬 정책

- 작성일: 2026-11-17
- 관련: 39번(버튜버 DB 구성안), 38번(데이터 현황), 09번(방송통계 기준정의서)

## 0. 결정 사항

| 항목 | 결정 |
|---|---|
| 상세 페이지 | **C안**: 등록 버튜버는 `/creator/{이름}` 하나(소개 / 방송 기록 탭). 방송 통계에서 등록 버튜버를 누르면 이 페이지의 방송 기록 탭으로 간다. `/analytics/streamer/{채널}`은 등록되지 않은 채널만 쓰고, 등록 버튜버의 이 주소는 상세로 이동(301) |
| 상단 메뉴 | 데뷔 캘린더 → 방송 통계 → 버튜버 DB (2026-11-17 반영) |
| 문구 | 해요체, 짧고 쉬운 말, 사람이 말하듯이(아래 8장) |

## 1. 목록에 올리는 버튜버

| 구분 | 목록 | 비고 |
|---|---|---|
| 공개 검토를 통과한 소개 | ✅ | 기본 대상 |
| 데뷔 예정(데뷔일이 미래) | ✅ | "데뷔 예정" 표시 |
| 일정 미정 | ✅ | "일정 미정" 표시 |
| 소개가 짧은 프로필 | ✅ | 목록에는 보인다. 검색 노출 여부(noindex)와는 별개 |
| 통계 수집·검색으로 자동 등록된 채널 기록 | ❌ | 버튜버 소개가 아니라 채널 기록 |
| 공개 보류·삭제된 소개 | ❌ | |

## 2. 활동 상태 (배지·필터에 쓰는 기준)

| 상태 | 기준 |
|---|---|
| 데뷔 예정 | 데뷔일이 오늘 이후. 7일 이내면 "D-n" |
| 방송 중 | 가장 최근 수집(10분)에서 방송 중 |
| 신입 | 데뷔 후 90일 이내 |
| 활동 중 | 최근 30일 방송 기록 1회 이상 |
| 쉬는 중 | 방송 기록은 있지만 최근 30일 없음 |
| 기록 없음 | 수집 대상이 아니거나(YouTube 등) 아직 기록이 없음. "활동 안 함"으로 해석하지 않는다 |

## 3. 정렬

### 3.1 기본 정렬: "새로운 순"
1. 곧 데뷔하는 버튜버 (데뷔가 가까운 순)
2. 이미 데뷔한 버튜버 (최근 데뷔순)
3. 일정 미정
4. 데뷔일 정보 없음

데뷔 캘린더 서비스라 "새로 만나는 버튜버"를 먼저 보여 준다.

### 3.2 선택 정렬

| 정렬 | 기준 | 조건(미달이면 "기록 없음" 묶음) |
|---|---|---|
| 새로운 순 (기본) | 3.1 | — |
| 평균 시청자순 | 최근 30일 방송 중 회차의 평균 시청자 | 최근 30일 방송 3회 이상 |
| 성장률순 | (최근 7일 평균 시청자 ÷ 데뷔 첫 7일 평균 시청자) − 1 | 데뷔 14일 이상, 두 기간 각각 방송 2회 이상, 첫 7일 평균 10명 이상(작은 분모로 숫자가 부풀지 않게) |
| 방송 많은 순 | 최근 30일 방송 시간 | 기록 있음 |
| 이름순 | 가나다 → 알파벳 → 그 밖 | — |

### 3.3 같은 값일 때
최근 데뷔순 → 이름순. 무작위로 섞지 않는다(볼 때마다 순서가 바뀌지 않게, 검색 로봇에도 같은 순서).

### 3.4 숫자가 없을 때
숫자 정렬에서 "기록 없음" 묶음은 항상 맨 뒤에 두고, 그 안에서는 새로운 순. 화면에는 0이 아니라 "기록 없음"으로 흐리게 표시한다.

## 4. 필터

| 필터 | 선택 | 묶는 방식 |
|---|---|---|
| 플랫폼 | 치지직 · SOOP · YouTube · Twitch | 같은 필터 안에서는 "또는" |
| 데뷔 시기 | 월 단위 | |
| 활동 상태 | 데뷔 예정 · 방송 중 · 신입 · 활동 중 | |
| 주요 콘텐츠 | 노래 · 게임 · 토크 · 그림 … (등록 태그) | |
| 방송 언어 | 한국어 · 일본어 · 영어 … | |
| 소속 | 소속 있음 | "개인"·"개인세"는 표시하지 않음 |
| 기록 | 방송 기록 있는 버튜버만 | |

서로 다른 필터끼리는 "그리고"로 묶는다.

## 5. 검색

순서: 이름 정확히 일치 → 이름이 검색어로 시작 → 이름에 포함 → 소속 일치 → 주요 콘텐츠 일치. 띄어쓰기·대소문자는 무시한다.

## 6. 나열 방식

| 항목 | 정책 |
|---|---|
| 보기 | 카드(기본) / 표. 표는 데스크톱 중심, 모바일은 핵심 칸만 |
| 카드 열 | 데스크톱 4열 · 태블릿 3열 · 모바일 2열 |
| 한 번에 | 24명 + "더 보기" 버튼(무한 스크롤 없음: 속도·검색 로봇) |
| 카드 정보 순서 | 사진 → 이름 → 플랫폼 / 소속 → 상태 배지 → 데뷔일 → 주요 콘텐츠 2개 → **정렬 기준 숫자 1개**(예: 평균 시청자순이면 평균 시청자) |
| 주소 | 필터·정렬은 주소에 남겨 공유 가능. 단 필터 주소는 검색 제외(noindex), 대표 주소는 `/creators` |
| 첫 HTML | 기본 정렬 앞 24명 + 요약 문장 |

## 7. 랭킹 띠 정책과 기준

### 7.1 공통 원칙

| 항목 | 기준 |
|---|---|
| 대상 | 버튜버 DB에 공개된 등록 버튜버 중 **치지직·SOOP** 채널(방송 기록을 모으는 플랫폼). YouTube·Twitch는 기록이 없어 제외 |
| 데뷔일 | 날짜가 확정된 소개만(데뷔 일시 확정·시간 미정). 날짜 미정·데뷔일 없음은 제외 |
| 플랫폼 | **치지직과 SOOP을 따로 순위 매긴다**(탭). 두 플랫폼은 시청자 수를 세는 방식과 수집 범위가 달라 한 줄로 비교하지 않는다 |
| 기본 지표 | **방송별 평균 시청자**: 한 방송 동안 기록된 시청자 수의 평균. 채널 값은 기간 안 방송별 평균의 **가운데 값(중앙값)**. 합방·호스트 유입 같은 한 번의 큰 방송이 순위를 뒤흔들지 않게 하기 위해서다 |
| 방송 1회 | 같은 방송 ID. 같은 날 껐다 다시 켠 방송은 각각 1회 |
| 방송한 날 | 한국 시간 기준 그날 방송 기록이 1회 이상 있는 날 |
| 갱신 | 매일 오전 6시(한국 시간), 전날까지의 하루 요약 표로 계산. 화면에 "○월 ○일 기준" 표시 |
| 수집이 불안정한 날 | 전날 수집 회차의 20% 넘게 실패하면 그날은 갱신하지 않고 직전 랭킹을 유지 |
| 표시 인원 | 플랫폼별 상위 5명. 자격을 갖춘 버튜버가 3명 미만이면 그 랭킹 띠는 숨긴다 |
| 공정성 | 운영자가 순위를 손으로 바꾸지 않는다. 소개가 비공개되면(사칭·부적절) 자동으로 빠진다. 기준은 집계 기준 페이지에 공개한다 |
| 표현 | "방송 기록 기준"을 함께 적는다. 잘함·못함 같은 평가 표현은 쓰지 않는다 |
| 이의 제기 | 문의 화면으로 받는다. 기록 오류가 확인되면 다음 갱신에 반영 |

### 7.2 이달의 성장

- **목적**: 최근 눈에 띄게 시청자가 늘어난 버튜버를 발견하게 한다.
- **지표**: 성장률 = 최근 값 ÷ 비교 값 − 1
  - 최근 값: 최근 30일 방송별 평균 시청자의 중앙값
  - 비교 값: 데뷔 60일 이상이면 **그 전 30일(31~60일 전)**의 중앙값, 데뷔 14~59일이면 **데뷔 첫 7일**의 중앙값
- **자격**
  - 데뷔 14일 이상
  - 최근 기간과 비교 기간에 각각 방송 3회 이상(데뷔 첫 7일 비교면 2회 이상)
  - 비교 값 10명 이상(작은 숫자로 성장률이 부풀지 않게)
  - 성장률 +10% 이상
- **순위**: 성장률 높은 순 → 같으면 최근 값 큰 순 → 최근 데뷔순
- **표시 예**: "+73% · 평균 180명 → 312명"

### 7.3 신입 시청자 TOP

- **목적**: 막 데뷔한 버튜버 중 지금 많이 보는 버튜버를 보여 준다.
- **대상**: 오늘 기준 데뷔 90일 이내
- **지표**: 최근 30일(데뷔 30일 미만이면 데뷔 이후) 방송별 평균 시청자의 중앙값
- **자격**: 해당 기간 방송 3회 이상
- **순위**: 지표 큰 순 → 같으면 방송 횟수 많은 순 → 최근 데뷔순
- **표시 예**: "평균 312명 · 데뷔 30일째"

### 7.4 꾸준히 방송한 신입

- **목적**: 시청자 수와 상관없이 데뷔 초반을 성실하게 이어 간 버튜버를 알린다(신입에게 공정한 노출 기회).
- **대상**: 데뷔 후 30일이 지났고 120일이 지나지 않은 버튜버(첫 30일 기록이 다 채워진 경우)
- **지표**: 데뷔일부터 30일 동안 **방송한 날 수**. 짧은 방송이 수집 간격 사이에 빠질 수 있어 방송 횟수 대신 날 수를 쓴다
- **자격**: 방송한 날 8일 이상
- **순위**: 방송한 날 많은 순 → 같으면 방송 시간 합 많은 순 → 최근 데뷔순
- **표시 예**: "데뷔 첫 30일 중 21일 방송"

### 7.6 (옵션) 팔로워 급상승 라벨

- 상태: **옵션 — 지금 만들지 않음.** 팔로워 수를 하루 1번 저장하는 작업(38번 3항)이 생긴 뒤 검토한다.
- 안: 최근 7일 팔로워 증가율이 같은 플랫폼 등록 버튜버 중 상위 10%이고, 7일 전 팔로워 100명 이상이며, 증가 수 50명 이상이면 카드에 "팔로워 급상승" 라벨.
- 치지직은 공개 팔로워 수가 있고, SOOP은 같은 방식의 값이 확인되기 전까지 제외.

### 7.5 알아 둘 한계(집계 기준 페이지에 함께 공개)

- 치지직 등록 버튜버는 15~20분 간격으로 확인하므로, 그보다 짧은 방송은 빠질 수 있다.
- SOOP은 카테고리 정보가 비는 경우가 있어 콘텐츠 관련 지표는 치지직보다 덜 정확하다.
- 방송 기록은 90일 동안 원본으로, 그 뒤에는 하루 요약으로 보관한다.

## 8. 문구 원칙

- 해요체, 한 문장은 짧게. 예: "VDébut에 등록된 버튜버를 한곳에 모았어요."
- 숫자 앞에 뜻을 먼저: "최근 30일 동안 12번 방송했어요"
- 기록이 없을 때 탓하지 않기: "아직 쌓인 방송 기록이 없어요"(○) / "활동이 없어요"(✕)
- 용어는 화면 전체에서 같게: 방송 기록, 평균 시청자, 데뷔 예정, 신입
- "개인"·"개인세"·"비영리"·"비상업" 표기 금지

## 9. 공정성

- 돈을 받고 보여 주는 소개나 순서는 반드시 "광고"로 표시한다(이용약관과 같음).
- 운영자가 정렬 기준과 다르게 순서를 바꾸지 않는다.
- 정렬·랭킹 기준은 집계 기준 페이지(`/analytics/method`)에 "버튜버 DB 랭킹" 항목으로 공개하고, 랭킹 띠마다 "기준 보기" 링크를 둔다.

## 10. 데이터 갱신

| 항목 | 주기 |
|---|---|
| 방송 중 표시 | 10분 |
| 숫자 칸·정렬·랭킹 | 하루 1번(채널별 하루 요약 표 기준) |
